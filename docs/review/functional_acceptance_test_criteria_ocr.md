# 功能验收测试判定标准

> **通用判定规则**：各测试项以指定日志文件中**能否记录**对应数据为准——能记录视为**通过**，否则视为**不通过**。

**行格式**（各 `*_acceptance.log` 统一；方括号内为规范测试项名称，**不写「验收项」三字，方括号后不写「验收内容：」**）：

```text
仿真时间=1.000s 仿真周期=1 [探测角度计算功能测试] 相对卫星ID=4 目标ID=1001 量测方位/俯仰=(12.312,18.491)°
```

**示例写作规则**（2026-08-28，文档口径）：

1. **只写规范原文指标**：一条验收行对应本条判定字段。本条 OCR 点名的字段必须写，**不因其它测试项也有同名字段而省略**；不把其它条目独占的量串写进来。
2. **禁止派生量**：不写由其它字段公式算出的量（如 SNR←功率比、航向←速度、抑制比←功率比、RMSE/CEP50/协方差迹、会话汇总统计、马氏距离² 等）。
3. **无则省略**：无有效值时不写该字段，不写 `无`/`0.000` 占位。
4. **分项拆分**：规范拆成多子项的（如脉压/MTI/MTD），示例仍用**规范测试项名**作方括号（如 `[目标信号增益功能测试]`），子指标在方括号后以 **`字段名=值`** 分行写出，不合并成「大包行」；库内检索关键字见各条「库内 `[…]`」说明，可与规范方括号不同。
5. **key=value**：方括号后每个量须显式 `字段名=值`（含单位），禁止裸写数值（如 `48.573dB`）。
6. **缺失**：库内无对等字段、本条尚未落盘的子指标，在该条「视为不通过」后写 **缺失。** 若能由本条已落盘字段或真值作差算出，再写 **可计算。**，**示例仍补该行**（key=判定指标名）。

**缺失项能否计算**（本文档判定句已标缺失的仅下列三条；示例已按可计算口径补行）：

| 项 | 缺失指标 | 能否计算 | 示例口径 |
|---|---|---|---|
| 32 | 总增益 | **能** | 脉压+MTI+MTD（dB）。主链分子是脉压+`target_processing_gain_db`，与此不同。 |
| 38 | 目标量测误差统计 | **能** | 量测−真值（斜距误差、方位/俯仰误差）。会话 RMSE 另见第 26 项。 |
| 42 | 估计误差指标 | **能** | 滤波 ECEF/速度−真值。 |
7. **存疑**：OCR 截图判定句无法确认（疑图片缺字、串行、与邻项完全相同等），在该条「视为不通过」后写 **存疑。** 示例仍按**测试项名称**区分，不以存疑句当作已冻结规范。
8. **身份字段**：面向天基红外 / RIR 雷达的示例行必须能看出「哪颗星或哪部雷达、哪个目标」。身份字段放在方括号后、指标 key 之前（第 24 项事件行除外：`事件=` 打头，随后 `卫星ID=` / `目标ID=`）。

| 对象 | 必写身份 | 说明 |
|---|---|---|
| SBIRS 相对某星的目标量 | `相对卫星ID=` + `目标ID=` | 双星示例 4 / 104；每星一行 |
| SBIRS 双星定位位置/距离（第 7 项） | `目标ID=` + 两颗 `相对卫星ID=` 与各自 `相对卫星斜距=` | 位置 LLA 只在双星定位时写，两星同一行，不拆行 |
| SBIRS 卫星自身量 | `卫星ID=` | 无目标时不写 `目标ID=` |
| 融合航迹 | `航迹键=` 或 `目标键=`；能映射时再写 `目标ID=` | 天基通道可另写 `源=实体N` |
| RIR 装备级（方向图、指向、扫描调度、波束表、调度策略） | `雷达ID=` | 示例取 `1` |
| RIR 干扰功率（第 30 项） | `干扰源ID=` | 一个 ID；不写平台/设备/发射三元组 |
| RIR 检测 / 测量 / 增益 | `目标ID=` | 已有则保持 |
| RIR 跟踪 / 识别 / 滤波 | `航迹=` + `目标ID=` | 两条都写，不能只写航迹 |

### 0A.1 外部验证前必须冻结的口径

1. 第 22、25 项“误差范围”采用 1σ、置信椭圆半长轴还是确定性上限。
2. 第 42 项真值为零或接近零时，位置/速度/加速度的绝对误差阈值。
3. 第 28 项 `52 dB` 是否允许显示精度或数值容差。
4. 第 15、21、25、38 项距离误差采用 ECEF 三维直线距离、地表大圆距离还是其它装备口径。
5. 第 44–47 项综合识别的有效样本集合、真值标签来源和按目标还是按周期计数。

## 0B. 外部导入测试项的数据责任划分

本节是 `测试.md` 新增条目的统一责任边界。一个测试项可以同时包含模型输出、
模型输入和模型不可见字段；分类按**字段来源**而不是按整条名称硬拆。只有模型实际测得、
计算得到或持有的结果才属于模型输出。当前公开输入接口已经传入的数据不算“模型无法获取”，
但也不因此要求模型把输入原样复制到正式输出或日志。只有输入接口中不存在、且不能由已有输入
唯一计算出的系统级事实，才归入外部仿真系统补充的数据。

本节不纳入第 56–69 项外部接口验收。第 70–77 项内部接口仍纳入日志责任：内部生产模块向
内部消费模块传递的关键中间量必须由模型自身记录，RIR 写入 `log/rir_acceptance.log`，SBIRS
写入 `log/opir_acceptance.log`；该记录是内部链路验收证据，不构成对外公开接口。

## 十、内部接口分析（模型内部子模块交互）

本节的“内部接口”只指同一模型实现内部的小模块调用。它不是模型间公共协议，也不应
为了验收而直接暴露 `src/` 内部类型。`测试2.md` 没有给出独立的内部接口测试名称和
判定阈值；按用户要求从现有实现链路整理 8 项内部接口测试，其中 RIR 雷达 4 项、
SBIRS 红外卫星 4 项，总数不超过 10。内部接口以“同周期、同目标/航迹、生产值与消费值
一致、非法输入不部分提交”为共同判据；验证记录是旁路证据，不构成新的 public API。

### 70. 雷达回波与环境功率交互接口测试

- **内部边界**：RIR 几何/雷达方程/环境功率计算模块 → 信号检测与处理模块。
- **交换数据**：周期号、雷达 ID、目标 ID、斜距、RCS、波束离轴增益、回波功率、热噪声、
  杂波功率、干扰功率、带宽、PRF 和有效积累脉冲数；功率统一使用 W 或显式 dBW。
- **验收判据**：同一周期和目标下，信号处理入口消费的回波与环境功率必须与上游计算结果
  一致；单位转换可逆，非有限值或非法链路必须拒绝且不得把部分功率快照提交给下游。
- **当前输出能力**：**大部分可观测**。第 29–35 项已经分项记录回波、噪声、杂波、干扰及
  处理增益，但尚无一条把生产模块与消费模块输入按同一关联键对账的接口记录。

### 71. 雷达信号处理与检测判决交互接口测试

- **内部边界**：RIR 信号处理/增益链 → CFAR 检测器与量测误差模块。
- **交换数据**：目标 ID、处理后信号功率、总噪声功率、脉压/MTI/MTD 增益、单脉冲 SNR、
  积累 SNR、虚警概率、统计门限、检测概率、检测标志、距离/角度误差标准差。
- **验收判据**：检测器输入应与信号处理输出同周期同目标；门限、Pd 和检测标志必须来自同一
  SNR 快照；检测失败不得生成有效量测，检测成功才允许向量测模块提交误差参数。
- **当前输出能力**：**大部分可观测**。第 32–36 项可核对增益、SNR 相关输入和 CFAR 结果，
  第 37–38 项可核对检测量测；积累 SNR 与误差模型入口尚缺统一接口行。

### 72. 雷达检测量测与航迹处理交互接口测试

- **内部边界**：RIR 检测/量测构造模块 → 全局关联器 → 航迹生命周期与 CV/IMM 滤波模块。
- **交换数据**：源目标索引、目标 ID、量测位置 ENU、速度种子、检测概率、RCS、3×3 量测
  协方差、关联键、是否命中既有航迹，以及未匹配量测/航迹集合。
- **验收判据**：量测协方差须有限且维度正确；同一量测最多关联一条航迹，同一航迹最多消费
  一条量测；关联键在生命周期内稳定；未匹配量测只能建新轨，未匹配航迹只能预测/失配推进。
- **当前输出能力**：**部分可观测**。第 37、38、41、42 项能够核对检测、角距、关联结果和
  航迹状态，但没有完整输出 3×3 量测协方差及未匹配集合，需内部契约测试补证。

### 73. 雷达航迹与特征识别交互接口测试

- **内部边界**：RIR 航迹滤波/生命周期模块 → 观测构造器与 RCS、运动、极化、HRRP 特征
  提取器 → 特征匹配/识别积累模块。
- **交换数据**：关联键、目标 ID、航迹状态、位置/速度/加速度、状态协方差或不确定度、SNR、
  RCS/极化/距离像样本、四维特征有效掩码与质量，输出类别、型号、置信度和积累状态。
- **验收判据**：只有有效航迹和有效特征维度参与识别；四维有效掩码必须与实际输入维度一致；
  识别结论的来源周期、批次和关联键可回溯，航迹回收或退出识别模式后不得复用旧积累状态。
- **当前输出能力**：**主要结果可观测**。第 40、42、44–47 项以及 `RirOutputFrame`、
  `RirRecognitionCycleSummary` 可核对大部分结果；特征提取器到匹配器的逐维输入需单元/契约测试。

### 74. 红外场景几何与视场门控交互接口测试

- **内部边界**：SBIRS 周期输入/坐标变换模块 → 地球遮挡、距离门和 WFOV/NFOV 视场门控模块。
- **交换数据**：周期号、UTC 儒略日、卫星 ID、目标 ID、卫星与目标 ECEF/ECI 状态、姿态与
  安装角、LOS、斜距、ECI 方位/俯仰、扫描中心和观测阶段。
- **验收判据**：同一周期内坐标参考系、角度单位和目标身份保持一致；被地球遮挡、越出距离带
  或越出实际视场的目标不得进入后续辐射检测候选，并必须给出可区分的结构化排除码。
- **当前输出能力**：**大部分可观测**。第 5–7、11–14 项可核对角度、范围和扫描状态，
  `SbirsCycleResult.issues` 可核对排除原因；完整中间坐标只保留在内部/归属诊断层。

### 75. 红外辐射噪声与检测判决交互接口测试

- **内部边界**：SBIRS 辐射/大气透过率模块与背景噪声模块 → WFOV/NFOV SNR 及检测判决模块。
- **交换数据**：目标辐射强度、斜距、接收孔径、光学透过率、大气透过率、量子效率、积分时间、
  背景辐射、光子/热/读出噪声、有效噪声、接收功率、信号能量、SNR、检测门限和检测标志。
- **验收判据**：SNR 判决必须消费同周期同目标、同观测阶段的辐射与噪声快照；WFOV/NFOV 使用
  各自门限；非法或非有限能量不得形成检测记录，检测标志必须与门限结果一致。
- **当前输出能力**：**主要结果可观测**。第 7、9、11、13、14 项及原始检测记录可以核对
  接收结果、SNR 和检测标志；光子/热/读出噪声分量未全部进入验收日志，内部测试可直接核对。

### 76. 红外宽场候选与窄场调度交互接口测试

- **内部边界**：SBIRS WFOV 候选/目标状态机 → NFOV 调度器 → 引导预测与 ATP 指向协调模块。
- **交换数据**：目标 ID、候选测角、量测时刻、SNR、连续命中状态、引导来源卫星 ID、候选状态、
  入列/选中结果、当前服务目标、指令方位/俯仰、指向稳定状态和捕获失败原因。
- **验收判据**：只有满足宽场候选条件的目标可进入调度；选择结果与锁定集合一致；跨星 cue 按
  来源 ID 和量测时间可追踪；未被选择或 ATP 未稳定的目标不得伪装成 NFOV 已捕获输出。
- **当前输出能力**：**部分可观测**。第 12–14 项、`wide_cue_measurements` 和归属诊断可核对
  候选、引导与捕获结果；完整内部队列和选择排序不进入 public API，应由调度器契约测试验证。

### 77. 红外量测与跟踪滤波交互接口测试

- **内部边界**：SBIRS NFOV 量测/误差模型 → `SbirsTrackingCoordinator` 的 EKF、IMM 或角度
  CV-KF → 目标状态机与输出构造模块。
- **交换数据**：目标 ID、量测时刻、方位/俯仰、动态 2×2 量测协方差、帧数、单帧/融合后
  角噪声、预测角、后验角、角速度、NIS、NIS 门结果、滑行/失锁状态和输出阶段。
- **验收判据**：滤波后端必须消费同周期同目标的量测与协方差；多帧协方差按有效帧数缩放；
  NIS 连续超门后释放锁定，缺量测周期只能预测/滑行；输出角和状态必须来自已提交的后验或预测。
- **当前输出能力**：**部分可观测**。第 13、14、18、55 项和归属诊断已有角度、帧数、噪声、
  NIS 与跟踪状态的一部分；完整滤波协方差和后端状态应由内部单元/快照测试验证。

### 内部接口边界总览（非新增测试项）

| 模型内部链路 | 内部交换内容 | 当前是否可形成外部证据 | 边界判断 |
|---|---|---|---|
| RIR 场景几何 → 回波功率计算 → 噪声/杂波/干扰 → 信号处理增益/CFAR | 目标角距、RCS、方向图增益、回波功率、环境噪声、处理增益、SNR、Pd、检测判决 | **可以分项输出**：第 28–36 项写入 `log/rir_acceptance.log`，方向图和扫描另有 CSV | 属模型内部信号链；对外只发布稳定结果或验收旁路，不暴露内部计算对象 |
| RIR 检测量测 → 关联 → 生命周期 → CV/IMM 滤波 | 量测、关联键、状态/协方差、命中/失配与航迹状态 | **部分可以**：第 37–42 项及归属记录可观测；完整点迹/滤波工作单元不属于 public API | 属模型内部跟踪链；外部模型通过正式输出/适配器消费，不直接调用关联器或滤波器 |
| RIR 航迹 → RCS/运动/极化/HRRP 特征 → 特征匹配与识别积累 | 航迹观测、四维特征、质量/相似度、类别/型号、识别摘要 | **可以输出主要产品**：`RirOutputFrame`、识别摘要及第 44–47 项；内部数据库匹配状态不直接输出 | 属模型内部识别链；第 65 项需要的是对外聚合投影，不是开放内部 tracker/matcher |
| SBIRS 场景几何 → 地球遮挡/视场 → 辐射/大气 → 背景噪声/SNR → 检测 | 目标 LOS、辐射强度、透过率、噪声统计、SNR、检测标志 | **可以输出主要观测**：原始角度、SNR、检测标志及第 5–11 项；内部噪声分解不全进 public API | 属模型内部红外探测链，对应第 58、67 项的部分字段来源 |
| SBIRS WFOV 扫描 → 候选状态机/调度 → ATP 指向 → NFOV 捕获/跟踪滤波 | 扫描相位、候选、锁定集合、引导、指向误差、NFOV 状态和协方差 | **部分可以**：第 12–14 项和归属诊断可观测；任务队列及完整滤波状态不是正式输出 | 属模型内部扫描跟踪链；外部任务只通过配置、补丁和 cue 驱动 |
| Session 输入校验 → Controller/Pipeline → 输出契约检查 | 校验问题、运行状态、中止原因、当前帧 | **可以结构化输出**：各 `*CycleResult.status/abort_reason/issues` | 属统一会话内部控制链，可支撑第 56、60、69 项的部分应答，但不是完整控制协议 |

内部链路的验收日志只能作为观测旁路：不得反向改变模型行为，不得把内部真值、归属信息
或诊断距离混入正式原始输出，也不得要求外部模型依赖内部类名或调用顺序。
