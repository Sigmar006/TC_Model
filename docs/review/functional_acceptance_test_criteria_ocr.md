# 功能验收测试判定标准

> **通用判定规则**：各测试项以指定日志文件中**能否记录**对应数据为准——能记录视为**通过**，否则视为**不通过**。

## 0. OCR 文件名 ↔ 仓库落盘

| OCR / 规范文件名 | 仓库实际路径 | 编译开关 |
|---|---|---|
| `Opir_acceptance.log` / `SatelliteTarget.log` | `log/opir_acceptance.log` | `ONEQ_ENABLE_OPIR_ACCEPTANCE_LOG` |
| `Fusion_acceptance.log`（第 11–14 项） | `log/opir_acceptance.log` 与 `log/fusion_acceptance.log` 各写一份、分别判定 | `ONEQ_ENABLE_OPIR_ACCEPTANCE_LOG`、`ONEQ_ENABLE_FUSION_ACCEPTANCE_LOG` |
| `Fusion_acceptance.log`（第 15–18 项） | `log/fusion_acceptance.log` | `ONEQ_ENABLE_FUSION_ACCEPTANCE_LOG` |
| `Rir_acceptance.log` / `RadarSingalProcessingDateFlow.log` | `log/rir_acceptance.log` | `ONEQ_ENABLE_RIR_ACCEPTANCE_LOG` |

| `integration_events.log` | 示例场景 `log_dir` 下 | 跑 examples 即写，无需库开关 |

**行格式**（各 `*_acceptance.log` 统一；方括号内为规范测试项名称，**不写「验收项」三字，方括号后不写「验收内容：」**）：

```text
仿真时间=1.000s 仿真周期=1 [探测角度计算功能测试] 相对卫星ID=4 目标ID=1001 量测方位/俯仰=(12.312,18.491)°
```

**示例写作规则**（2026-08-28，文档口径）：

1. **只写规范原文指标**：一条验收行对应本条判定字段。本条 OCR 点名的字段必须写，**不因其它测试项也有同名字段而省略**；不把其它条目独占的量串写进来。
2. **禁止派生量**：不写由其它字段公式算出的量（如 SNR←功率比、航向←速度、抑制比←功率比、RMSE/CEP50/协方差迹、会话汇总统计、马氏距离² 等）。
3. **无则省略**：无有效值时不写该字段，不写 `无`/`0.000` 占位。
4. **分项拆分**：规范拆成多子项的（如脉压/MTI/MTD），示例仍用**规范测试项名**作方括号（如 `[目标信号增益功能测试]`），子指标在方括号后以 **`字段名=值`** 分行写出，不合并成「大包行」；库内检索关键字见各条「库内 `[…]`」说明，可与规范方括号不同。
5. **key=value**：方括号后每个量须显式 `字段名=值`（含单位），禁止裸写数值（如 `48.573dB`）。
6. **缺失**：库内无对等字段、本条尚未落盘的子指标，在该条「视为不通过」后写 **缺失。** 若能由本条已落盘字段或真值作差算出，再写 **可计算。**，**示例仍补该行**（key=判定指标名）。

**缺失项能否计算**（本文档判定句已标缺失的仅下列三条；示例已按可计算口径补行）：

| 项 | 缺失指标 | 能否计算 | 示例口径 |
|---|---|---|---|
| 32 | 总增益 | **能** | 脉压+MTI+MTD（dB）。主链分子是脉压+`target_processing_gain_db`，与此不同。 |
| 38 | 目标量测误差统计 | **能** | 量测−真值（斜距误差、方位/俯仰误差）。会话 RMSE 另见第 26 项。 |
| 42 | 估计误差指标 | **能** | 滤波 ECEF/速度−真值。 |
7. **存疑**：OCR 截图判定句无法确认（疑图片缺字、串行、与邻项完全相同等），在该条「视为不通过」后写 **存疑。** 示例仍按**测试项名称**区分，不以存疑句当作已冻结规范。
8. **身份字段**：面向天基红外 / RIR 雷达的示例行必须能看出「哪颗星或哪部雷达、哪个目标」。身份字段放在方括号后、指标 key 之前（第 24 项事件行除外：`事件=` 打头，随后 `卫星ID=` / `目标ID=`）。
9. **文件独立判定**：每个验收用例指定的日志文件是该用例的唯一判定证据。同一字段即使已写入其它日志，只要本用例还指定另一个文件，就必须在该文件中再次输出；不得引用、链接或读取其它日志代替。多个文件之间允许字段和记录重复，分别按各自用例要求生成。

| 对象 | 必写身份 | 说明 |
|---|---|---|
| SBIRS 相对某星的目标量 | `相对卫星ID=` + `目标ID=` | 双星示例 4 / 104；每星一行 |
| SBIRS 双星定位位置/距离（第 7 项） | `目标ID=` + 两颗 `相对卫星ID=` 与各自 `相对卫星斜距=` | 位置 LLA 只在双星定位时写，两星同一行，不拆行 |
| SBIRS 卫星自身量 | `卫星ID=` | 无目标时不写 `目标ID=` |
| 融合航迹 | `航迹键=` 或 `目标键=`；能映射时再写 `目标ID=` | 天基通道可另写 `源=实体N` |
| RIR 装备级（方向图、指向、扫描调度、波束表、调度策略） | `雷达ID=` | 示例取 `1` |
| RIR 干扰功率（第 30 项） | `干扰源ID=` | 一个 ID；不写平台/设备/发射三元组 |
| RIR 检测 / 测量 / 增益 | `目标ID=` | 已有则保持 |
| RIR 跟踪 / 识别 / 滤波 | `航迹=` + `目标ID=` | 两条都写，不能只写航迹 |
| 不强制 | — | 模块计时（50–54）、AHP（27）、连续运行次数 |

## 0B. 外部导入测试项的数据责任划分

本节是 `测试.md` 新增条目的统一责任边界。一个测试项可以同时包含模型输出、
模型输入和模型不可见字段；分类按**字段来源**而不是按整条名称硬拆。只有模型实际测得、
计算得到或持有的结果才属于模型输出。当前公开输入接口已经传入的数据不算“模型无法获取”，
但也不因此要求模型把输入原样复制到正式输出或日志。只有输入接口中不存在、且不能由已有输入
唯一计算出的系统级事实，才归入外部仿真系统补充的数据。

本节不纳入第 56–69 项外部接口验收。第 70–77 项内部接口仍纳入日志责任：内部生产模块向
内部消费模块传递的关键中间量必须由模型自身记录，RIR 写入
`log/RadarInternalInterface.log`，SBIRS 写入 `log/IRInternalInterface.log`；该记录是内部链路
验收证据，不构成对外公开接口。

### 0B.1 传感器或业务模型能够获得并输出的数据

| 数据类别 | 模型侧可以输出的字段 | 涉及新增要求 |
|---|---|---|
| RIR 检测与量测 | 检测标志、斜距、方位、俯仰、SNR、Pd、量测协方差，以及内部链路的回波/噪声/增益/门限旁路证据 | 对目标角距测量、跟踪滤波、第 70–72 项内部接口 |
| RIR 航迹与识别 | 航迹键、状态、估计位置/速度/加速度、状态协方差、集群估计数量、类别/型号/置信度、RCS/运动/极化/HRRP 特征摘要 | 多目标跟踪、规模目标识别、综合特征识别、第 73 项内部接口 |
| RIR 外部干扰输入 | 干扰源/发射标识、位置和速度、波形类型、活动时窗、中心频率、带宽、发射功率、天线和极化 | 第 63 项外部干扰输入接口；雷达据此计算传播、时频重叠、到达功率及接收机影响 |
| RIR 装备与调度 | 天线峰值增益、波束宽度、扫描中心和驻留预算 | 天线方向图、搜索和跟踪功能 |
| SBIRS 原始观测 | 检测 ID、量测时刻、方位/俯仰、IR SNR、检测标志、WFOV/NFOV 阶段 | 目标可探测性、宽/窄场探测、第 74–75 项内部接口 |
| SBIRS 归属与诊断 | 目标 ID、估计/引导距离、最大探测距离、焦平面脱靶量、指向误差、NIS、捕获/失锁原因、引导来源星 ID | 宽窄场联合、窄场跟踪、第 76–77 项内部接口；这些字段不得伪装成被动红外正式测距 |

| Inference / Precision / Threat | 预测轨迹、预测发射点、预测关机点、预测落点、模型给出的不确定度、精度指标、威胁分和等级 | 第 20–27 项的预警预测与精度评估功能 |

功能测试日志写上述**模型原始输出值**；内部接口日志还须写生产值、消费值及周期、目标或航迹
关联键，以便确认内部传递一致。如果已有模型输出包含误差估计或协方差，可以原样输出；但不为
外部验收额外增加“与真值误差”“误差百分比”“是否通过”等比较字段。

下表数据虽然来源于外部仿真系统，但已经进入当前模型的公开输入面，因此**不再列入“模型无法
获取、需要外部额外提供”**。它们只作为计算条件或外部验收基准；除非某一正式输出契约另有
明确要求，模型不需要在输出日志中复写这些输入。

| 输入可知类别 | 当前公开输入接口中的数据 | 使用边界 |
|---|---|---|

| 传感器平台状态 | RIR 平台 ECEF 位置；SBIRS 卫星 ECEF 位置、速度和姿态 | 可计算传感器—目标几何、真值 LOS 和真值距离；不属于额外外部字段 |

| 传感器功能配置 | `RirSessionConfig`、`SbirsSessionConfig` 及两类 `RuntimeConfigPatch` 中与天线、扫描、测角、检测和跟踪功能有关的参数 | 已有配置仅作为模型计算条件，不要求在验收日志中逐项回显 |
| 可由上述输入唯一计算的基准 | 单周期目标数量、目标—传感器真值距离、真值方位/俯仰、场景给定类别或特征标签 | 验证程序可直接从同一输入快照计算，不新增模型输出字段，也不归入接口缺失 |

### 0B.3 当前模型确实无法从输入接口获得、必须由外部仿真系统保留的数据

| 模型不可见类别 | 外部系统负责提供或记录的字段 | 原因与边界 |
|---|---|---|
| 跨时段语义真值 | 当前接口没有显式事件标志的实际发射、关机、落点事件及其冻结判定时刻 | 单周期目标状态不足以唯一确定事件语义；若测试夹具已按冻结算法从完整输入序列算出，则由夹具保留，不回灌传感器日志 |
| 输入中没有的业务身份 | 卫星地面站名称、消息来源/目的模型、分发对象、标准化封装版本 | 这些是仿真编排或消息总线属性，不是传感器算法状态；信息源名称已由融合输入 DetectionRecord.source_name 显式传入 |
| 外部投递结果 | 消息是否送达、接收方回执、跨模型因果链是否完整 | 传感器只能报告自身提交结果，不能证明外部接收成功 |
| 验收规则与汇总结论 | 容差配置、有效样本筛选规则、跨周期统计、误差/正确率汇总和最终通过/失败 | 属外部验证器职责，不是传感器输入或业务输出 |

外部系统可以把这些不可见字段写入独立验证报告或测试夹具结果；不得要求传感器把外部事实
复制进正式原始输出，也不得把路由名称、验收阈值或通过结论硬编码进传感器算法。

### 0B.4 误差与阈值只作为模型输出约束

以下约束由外部验证程序使用“模型原始输出 + 当前模型输入中的真值，或模型不可见的外部
事件真值”计算。模型日志保留被比较的
原始输出即可，**不要求新增误差值、误差比例或通过标志**。已有日志本来就包含某个误差值时
可以保留，但它不是新增接口的必写字段。

| 测试项 | 模型日志保留的输出 | 判定基准与计算（不进模型日志） | 输出约束 |
|---|---|---|---|

### 70. 雷达回波与信号处理交互接口测试

- **内部边界**：RIR 几何/传播与雷达方程回波计算模块 → 信号处理与增益链。
- **交换数据**：周期号、雷达 ID、目标 ID、斜距、RCS、波束离轴增益、回波功率、回波时延、
  双程多普勒频移、脉压增益、匹配滤波带宽、PRF 和有效积累脉冲数；功率统一使用 W，
  时延使用 s，频率使用 Hz。
- **验收判据**：同一周期和目标下，信号处理入口消费的回波功率、时延及多普勒频移必须与
  回波计算结果一致；脉压增益和波形参数必须来自同一 detection cell，非有限值或非法链路
  必须拒绝且不得向下游提交部分回波快照。
- **当前输出能力**：**可观测**。第 29 项提供回波功率旁证；同一 detection cell 另写第 70 项
  接口行，记录回波功率、时延、多普勒频移及波形参数，按周期、雷达 ID 和目标 ID 对账，
  并分别标识回波计算输出值与信号处理入口消费值。

### 71. 雷达信号处理与检测判决交互接口测试

- **内部边界**：RIR 信号处理/增益链 → CFAR 检测器与量测误差模块。
- **交换数据**：目标 ID、处理后信号功率、总噪声功率、脉压/MTI/MTD 增益、单脉冲 SNR、
  积累 SNR、虚警概率、统计门限、检测概率、检测标志、距离/角度误差标准差。
- **验收判据**：检测器输入应与信号处理输出同周期同目标；门限、Pd 和检测标志必须来自同一
  SNR 快照；检测失败不得生成有效量测，检测成功才允许向量测模块提交误差参数。
- **当前输出能力**：**可观测**。第 71 项接口行使用同一快照输出处理 SNR、CFAR 消费
  SNR、积累 SNR、总噪声、增益、门限、Pd 和检测标志；无 detection cell 时不伪造缺失的分项功率。

### 72. 雷达检测量测与航迹处理交互接口测试

- **内部边界**：RIR 检测/量测构造模块 → 全局关联器 → 航迹生命周期与 CV/IMM 滤波模块。
- **交换数据**：源目标索引、目标 ID、量测位置 ENU、速度种子、检测概率、RCS、3×3 量测
  协方差、关联键、是否命中既有航迹，以及未匹配量测/航迹集合。
- **验收判据**：量测协方差须有限且维度正确；同一量测最多关联一条航迹，同一航迹最多消费
  一条量测；关联键在生命周期内稳定；未匹配量测只能建新轨，未匹配航迹只能预测/失配推进。
- **当前输出能力**：**可观测**。第 72 项逐量测输出 ENU 位置、速度种子、Pd、RCS、
  3×3 量测协方差、关联键及新建/更新航迹结果；未匹配航迹集合仍由内部契约测试补证。

### 73. 雷达航迹与特征识别交互接口测试

- **内部边界**：RIR 航迹滤波/生命周期模块 → 观测构造器与 RCS、运动、极化、HRRP 特征
  提取器 → 特征匹配/识别积累模块。
- **交换数据**：关联键、目标 ID、航迹状态、位置/速度/加速度、状态协方差或不确定度、SNR、
  RCS/极化/距离像样本、四维特征有效掩码与质量，输出类别、型号、置信度和积累状态。
- **验收判据**：只有有效航迹和有效特征维度参与识别；四维有效掩码必须与实际输入维度一致；
  识别结论的来源周期、批次和关联键可回溯，航迹回收或退出识别模式后不得复用旧积累状态。
- **当前输出能力**：**主要交互可观测**。第 73 项按航迹关联键输出航迹状态、位置/速度、
  SNR、特征有效掩码、来源周期/批次和识别结果；特征提取器私有的逐维中间状态仍由单元/契约测试补证。


### 74. 红外场景几何与视场门控交互接口测试

- **内部边界**：SBIRS 周期输入/坐标变换模块 → 地球遮挡、距离门和 WFOV/NFOV 视场门控模块。
- **交换数据**：周期号、UTC 儒略日、卫星 ID、目标 ID、卫星与目标 ECEF/ECI 状态、姿态与
  安装角、LOS、斜距、ECI 方位/俯仰、扫描中心和观测阶段。
- **验收判据**：同一周期内坐标参考系、角度单位和目标身份保持一致；被地球遮挡、越出距离带
  或越出实际视场的目标不得进入后续辐射检测候选，并必须给出可区分的结构化排除码。
- **当前输出能力**：**可观测**。第 74 项按 WFOV/NFOV 阶段输出斜距、LOS、ECI 角、
  传感器系视场门输入及门控结果；`SbirsCycleResult.issues` 保留结构化排除原因。

### 75. 红外辐射噪声与检测判决交互接口测试

- **内部边界**：SBIRS 辐射/大气透过率模块与背景噪声模块 → WFOV/NFOV SNR 及检测判决模块。
- **交换数据**：目标辐射强度、斜距、接收孔径、光学透过率、大气透过率、量子效率、积分时间、
  背景辐射、光子/热/读出噪声、有效噪声能量（J）、接收功率、信号能量、SNR、检测门限、
  SNR 门结果、视场门结果、稳定帧门结果和综合准入结果。
- **验收判据**：SNR 判决必须消费同周期同目标、同观测阶段的辐射与噪声快照；WFOV/NFOV 使用
  各自门限；非法或非有限能量不得形成检测记录；SNR 门结果必须与门限比较一致，综合准入结果
  必须同时反映视场、SNR，以及 NFOV 稳定帧条件。
- **当前输出能力**：**可观测**。第 75 项按 WFOV/NFOV 阶段输出辐射/能量、光子/热/读出
  噪声分量、有效噪声能量、辐射噪声模块输出 SNR、判决入口消费 SNR、门限、分项门结果和
  综合准入结果。


### 76. 红外宽场候选与窄场调度交互接口测试

- **内部边界**：SBIRS WFOV 候选/目标状态机 → NFOV 调度器 → 引导预测与 ATP 指向协调模块。
- **交换数据**：目标 ID、候选测角、量测时刻、SNR、连续命中状态、引导来源卫星 ID、候选状态、
  入列/选中结果、当前服务目标、指令方位/俯仰、指向稳定状态和捕获失败原因。
- **验收判据**：只有满足宽场候选条件的目标可进入调度；选择结果与锁定集合一致；跨星 cue 按
  来源 ID 和量测时间可追踪；未被选择或 ATP 未稳定的目标不得伪装成 NFOV 已捕获输出。
- **当前输出能力**：**可观测**。第 76 项输出候选测角、时刻、SNR、连续命中、引导来源、
  入列/选中结果、当前服务目标、指令角、指向稳定状态及捕获失败原因；完整排序算法仍由调度器契约测试验证。

### 77. 红外量测与跟踪滤波交互接口测试

- **内部边界**：SBIRS NFOV 量测/误差模型 → `SbirsTrackingCoordinator` 的 EKF、IMM 或角度
  CV-KF → 目标状态机与输出构造模块。
- **交换数据**：目标 ID、量测时刻、方位/俯仰、动态 2×2 量测协方差、帧数、单帧/融合后
  角噪声、预测角、后验角、角速度、NIS、NIS 门结果、滑行/失锁状态和输出阶段。
- **验收判据**：滤波后端必须消费同周期同目标的量测与协方差；多帧协方差按有效帧数缩放；
  NIS 连续超门后释放锁定，缺量测周期只能预测/滑行；输出角和状态必须来自已提交的后验或预测。
- **当前输出能力**：**量测更新可观测**。第 77 项输出实际滤波量测、2×2 量测协方差、帧数、
  单帧/融合角噪声、后验角、NIS 门结果和跟踪/滑行状态；完整滤波状态由内部快照测试验证。
