## 3. 遗漏（缺字段）

### 3.1 「稳定帧」路径缺 `目标辐射强度` / `大气透过率`

- 噪声判决段共 **124 327** 条，其中 **34 890 条（28.1%）** 无 `目标辐射强度` 与 `大气透过率`。
- 这些条目的形态是：

```
阶段=NFOV 接收功率=6.420e-013W 信号能量=6.420e-013J 光子噪声=0.000J 热噪声=6.647e-011J
读出噪声=0.000J 有效噪声能量=6.647e-011J 辐射噪声模块输出SNR=0.009659
判决模块输入SNR=0.009659 门限=0.001000 SNR门结果=通过 视场门结果=通过
稳定帧门结果=通过 综合准入结果=通过
```

- 即：锁定后走"稳定帧"分支时不再打印入射辐射强度与大气透过率，**只剩接收功率** ⇒ 该批帧的链路预算无法反算。

### 3.2 地球遮挡记录缺 `斜距`

- 遮挡记录 **102 485** 条仅有 `遮挡余量`，无 `斜距`。
- 遮挡与"能否测到斜距"无关（几何上仍可算），当前实现属**提前 return** 造成的字段缺失。

## 4. 两个高优先级发现（非零值，但比零值更严重）

### 4.1 `红外辐射强度` 对所有目标恒为同一常数

| 目标 | 明细行数 | 取值个数 | 值 |
|---|---|---|---|
| 99 / 100 / 102 / 103 / 104（地面站、指挥所） | 各 26 124 | 1 | `10388.114607` |
| **101（洲际弹道导弹）** | 17 820 | 1 | `10388.114607` |
| 105–110（**卫星自身**） | 各 21 770 | 1 | `10388.114607` |

**全部 11 个目标、279 060 条记录，辐射强度只有一个取值。**

根因（`opir_sensor_1q.cpp:387-389`）：

```cpp
const double intensity = target.irar_;
scene_target.radiant_intensity_w_per_sr =
    (intensity > 0.0 && std::isfinite(intensity)) ? intensity : kDefaultRadiantIntensityWPerSr;
```

`kDefaultRadiantIntensityWPerSr = 10388.1146065573`（`opir_sensor_1q.cpp:60`，
等价 1200 K 黑体、ε=0.85、A=1 m²、3–5 µm，见 `SbirsSceneTypes.h:35,41`）。

而 `irar_` 取自 `_unit_info->irar_`，**两处模型类的赋值被注释掉了**：

- `cyairportData.cpp:58`　`// irar_ = _unit_info->irar_;`
- `CyQPEGVehicleData.cpp:58`　`// irar_ = _unit_info->irar_;`

⇒ 这些单元类型 `irar_` 恒为 0 ⇒ 全部落到默认常数。

**影响**：红外辐射强度维度**零区分度**（导弹 = 地面站 = 卫星），
SBIRS 无法据此判别目标类型；而它同时是 `SNR` 的唯一信号项，
故 `IR_SNR` 只随距离变化（实测 `0.001049…0.012237`）。

## 5. 结论与建议

**完整性**：时间与卫星维度**无遗漏**；零值分为"配置缺失（4 项）"、"语义/哨兵（2 项）"、
"正常（2 项）"三类；缺字段有 2 处。

**按优先级建议**：

1. **恢复 `irar_` 赋值**（`cyairportData.cpp:58`、`CyQPEGVehicleData.cpp:58`），
   让红外辐射强度按目标/姿态/波段给出真实值 —— 这是红外识别能力的前提。
2. **补齐噪声模型**：`光子噪声`、`读出噪声`、`背景辐射亮度`。
   建议至少接入背景辐射与光子噪声，否则噪声底恒定、SNR 只随距离变化。
3. **给角量测加噪声**（`融合角噪声` 当前恒 0），并复核 109 星的几何/协方差，
   解决 NIS 74% 超门 —— 这直接关系到 SBIRS 融合能否持续给出可用引导。
4. **补字段**：「稳定帧」路径补 `目标辐射强度`/`大气透过率`；遮挡记录补 `斜距`。
5. **修 `剩余角` 语义**：改为 `|实际指向 − 指令指向|`，否则稳定态恒 0 无意义。
