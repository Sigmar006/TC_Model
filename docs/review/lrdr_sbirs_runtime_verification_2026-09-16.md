## 1. 结论

本次使用当前源码重新编译并独立运行 LRDR 与 SBIRS 红外场景。两个场景均正常结束，
70–77 项内部接口均有连续日志，未发现 `NaN`、`Inf`、负协方差或明显量纲错误。

综合判定如下：

| 检查维度 | LRDR | SBIRS 红外 |
|---|---|---|
| 程序可运行、日志可生成 | 通过 | 通过 |
| 内部主链指标是否有输出 | 通过 | 通过 |
| 已输出数值的基本物理/数学一致性 | 基本通过 | 基本通过 |
| 与第 70–77 项所列全部交换字段相比是否完整 | 部分完整 | 部分完整 |
| 当前场景能否证明完全不依赖真值 | 不通过 | 不通过（默认 EKF） |
| 能否据此证明合同性能全部达标 | 不能 | 不能 |

算法不是简单返回固定常量的“假实现”：雷达方程、噪声/SNR、随机检测、量测协方差、
关联/滤波、红外辐射噪声、视场门控和 NIS 均实际执行，输出也随距离、角度、周期和目标变化。
但是当前验收场景存在真值辅助或旁路，且部分日志的“生产值/消费值”取自同一个运行期变量，
只能证明接口记录一致，不能代替独立参考算法对拍。

### 3.2 核心问题

**高优先级：检测标志与量测准入口径不一致。** 43 条第 71 项记录为“检测标志=否”，
但这 43 个同周期、同目标键全部仍产生了第 72 项有效量测。原因是场景配置使用
`gate_mode = kSnrFallback`，控制器按 SNR 是否大于 6 dB准入，而日志中的检测标志来自
随机检测器判决。该行为与第 71 项“检测失败不得生成有效量测”的文字判据冲突，会使跟踪
命中率和航迹连续性偏高。

**高优先级：量测位置使用真值。** `kSnrFallback` 分支将场景目标 ENU 位置直接作为量测位置，
只附加误差协方差，不采样量测噪声。实现位置见
`src/remote_identification_radar/runtime/RirController.cpp:779` 和 `:795`，场景开关见
`examples/scenes/rir_ground_site_recognition/rir_ground_site_recognition.json:308`。
因此本次关联和滤波结果不能证明真实误差条件下的性能。

**中优先级：字段只达到“主要交互可观测”。** 第 71 项未直接记录处理后信号功率、Pfa、
距离/角度误差标准差；第 72 项未记录未匹配量测/航迹集合；第 73 项未记录加速度、状态
协方差及逐维特征质量。这些数据在算法内部部分存在，但当前单行日志不足以证明全部交换字段。

### 4.2 核心问题

**高优先级：默认 EKF 由目标真值状态初始化。** 当前场景未覆盖 `estimated_backend`，因此使用
默认 `kEkf`；初始化直接写入目标 ECI 真值位置和速度，见
`src/sbirs_sensor/pipeline/SbirsTrackingCoordinator.cpp:35`。后续预测、量测更新和 NIS 是真实
滤波计算，但初始条件受到真值辅助，不能作为完全自主捕获/起始性能证据。角度 CV-KF 分支才是
仅使用测角初始化的分支。

**中优先级：检测门限过低，未形成有效反例。** 场景把 WFOV/NFOV 门限都设为 `0.001`，
库默认分别为 4 和 6；本次所有 SNR 都约为 70，因此所有 SNR 门均通过。当前拒绝样本来自视场
或稳定帧条件，不能证明低 SNR 检测拒绝逻辑在集成场景中有效。

**中优先级：NIS 失锁未验。** 本次有 18 次 NIS 超门，但默认
`nis_gate_loss_cycles=0` 禁用了连续超门失锁，所有量测更新仍处于“跟踪”。第 77 项只输出
后验角，没有完整输出预测角、角速度和滤波状态协方差，完整性仍需内部快照测试补证。

## 6. 是否是假值

| 观察 | 判断 |
|---|---|
| 距离变化时回波功率、时延、多普勒、SNR、Pd、协方差连续变化 | 不是固定常量输出 |
| 红外距离、视角、接收功率、SNR、测角、协方差和 NIS 连续变化 | 不是固定常量输出 |
| 噪声功率或目标 RCS 在单一场景内保持常量 | 来自固定硬件/目标配置，本身不能认定为假值 |
| 接口“输出值”和“入口值”完全相等 | 符合传递语义，但当前由同一快照记录，不是独立消费者对拍 |
| LRDR 真值位置回退、SBIRS EKF 真值初始化 | 属真实算法外的真值辅助，会高估性能，应在正式验收场景关闭 |

因此准确表述应为：**算法主体存在且实际运行，输出不是简单伪造常量；但当前场景包含真值
辅助和宽松门限，尚不能作为合同算法独立性及完整性能的最终验收证据。**

## 7. 建议整改顺序

1. LRDR 正式验收场景改为检测器门控，量测位置走误差采样；增加断言：检测标志为否时不得产生第 72 项量测。
2. SBIRS 正式验收使用仅由量测初始化的角度 CV-KF，或增加不读取目标真值的 EKF 初始化方案。
3. 红外门限恢复到有物理意义的配置，并增加低于/高于门限两组样本；启用有限的 NIS 连续超门失锁周期。
4. 为第 71、73、75、77 项补齐目前未落盘的关键交换字段，或明确将其划归快照/契约测试，不再声称单日志全字段覆盖。
5. 用独立验证器从输入重算回波、SNR、协方差和门控结果，避免仅比较同一变量的两个标签。
