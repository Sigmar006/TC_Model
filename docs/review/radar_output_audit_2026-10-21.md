## 1. 真·不合理（P1，建议修）

### 1.1 综合特征识别恒为"未知"

```
[综合特征识别功能测试] 航迹=1 目标ID=101 目标类别=未知          （1,903 行全部如此）
[雷达航迹与特征识别交互接口测试] … 类别=未知 型号=未识别 置信度=0.11331 积累观测数=1
```

匹配分仅 **0.10–0.11**，低于 `acceptance_score` 门限 ⇒ 状态恒 `kUnknown`。
第 46/47 项的特征明明都在产出（极化 11,418 行、宽带一维像 1,903 行、运动特征 1,903 行），
却匹配不上库内模板。**最可能是 1.2 的退化极化特征把匹配分拖死**。

### 1.2 极化三项特征全轮常量、标准差恒 0

| 字段 | 取值（11,418 行唯一值） |
|---|---|

| 本征极化方向角均值/标准差 | **0.000° / 0.000°** |
| 本征极化椭圆率均值/标准差 | **−8.547° / 0.000°** |

方向角恒 0.000°、标准差恒 0.0000 ⇒ S 矩阵 `hh/hv/vh/vv` 在整轮里**完全不变**，
与目标姿态、视角、时间无关。第 46 项"极化特征解算"实质在验一个常量。

### 1.3 点迹速度种子恒 0

```
[雷达检测量测与航迹处理交互接口测试] … 速度种子=(0.000,0.000,0.000)m/s  （1,481 行全部）
```

速度维量测从未生成。物理上可解释：PRF=10 Hz ⇒ 无模糊速度仅 ±0.25 m/s，
对 1.6 km/s 目标必然模糊；但作为"输出参数"它恒 0，等于没有信息，应标"不适用(速度模糊)"。

### 1.4 外部干扰输入两处口径问题

```
[外部干扰输入雷达接口测试] … 波形=带限噪声 中心频率=3000000000.000Hz 带宽=10000000.000Hz \
  发射功率=5.012e+001W 峰值增益=-5.500dBi 极化=4
```

- **峰值增益 = −5.5 dBi**：天线"峰值增益"为负值不合理（除非口径是"相对某参考的差值"）；
- **极化 = 4**：判据要求记录"极化方式"，这里只打印枚举序号，外部程序无法直接判读。
