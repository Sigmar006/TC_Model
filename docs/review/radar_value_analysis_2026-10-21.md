# 雷达输出数值合理性分析（2026-10-21 17:38 轮）

数据：`RadarOutput.log`（30.4 MB / 23 项）、`RadarExternalInterface.log`（290 MB / 5 项）、
`RadarInternalInterface.log`（2.5 MB / 4 项）；DLL 2026-10-21 17:34:53
方法：逐项提取数值字段的取值集合与极值，再按物理关系做跨项一致性核算

## 一、不符合实际（按严重度排序）

### 1. 航迹速度偏低 2.4 倍（第 45 / 65 项）

| 量 | 值 |
|---|---|
| 第 45 项「跟踪滤波」速度 | 1.6–1.9 km/s |
| 第 65 项「航迹识别」速度 | 同上（同一后验） |
| 真值（场景位置差分，中位） | **4,495 m/s** |

位置量测协方差 `diag=[7.05e6, 2.37e7, 3.04e7] m²`（σ=2.7/4.9/5.5 km），单雷达位置-only
观测下速度不可观，滤波器稳态只到 1.9 km/s。识别侧已用 20 拍最小二乘修正（4,218 m/s，误差 6%），
但**对外输出的航迹速度仍是 1.9 km/s**。

### 2. 极化三项形状量仍恒定（第 46 项）

| 量 | 取值 |
|---|---|
| 行列式均值/标准差 | 1,870 种 ✅ |
| 功率迹（Span）均值/标准差 | 1,845 种 ✅ |
| **去极化系数** | **1 种（0.0012/0.0000）** ❌ |
| **本征极化方向角** | **1 种（0.000°/0.000°）** ❌ |
| **本征极化椭圆率** | **1 种（−8.547°/0.000°）** ❌ |

根因（`lrdr_sensor_features.cpp::LoadPolarization`）：按参数生成字典时，四个通道加的是**同一个**
形状项：

```cpp
shape = 0.5·az_var·(az/half_az) + 0.5·el_var·((el−el_c)/half_el);
hh = hh_amp + shape;  vv = vv_amp + shape;
hv = hh_amp + shape − isolation;  vh = hh_amp + shape − isolation;
```

公共模偏置只改**幅度**，不改**通道比值**，而去极化系数与 Graves 的 ψ/τ 都是比值量。
⇒ 10-21 的 `azimuth_variation_db=6.0` 只让行列式/Span 动了起来，三个形状量仍无信息。
要修需引入**通道间差异项**（HH 与 VV 独立变化、HV 隔离度随视角变化）。

### 3. 第 33 项总增益出现负值

`总增益` 中位 50.59 dB（正常，= 脉压 48.57 + MTI/MTD），但 **3 行**为负（最低 −3.365 dB）；
负的总增益意味着接收链"亏增益"，物理上不合理（集中在首拍瞬态）。

### 4. MTI 增益 33% 为负

`MTI增益` 范围 −51.9 … +6.0 dB，**435/1,335 行为负**。对多普勒接近零的目标 MTI 近乎全抑制，
可以解释，但占比偏高，说明目标径向速度在部分周期接近零（与 1.9 km/s 的低估一致）。

### 5. 原始 SNR 与报出的 SNR 差 50.4 dB（口径未标注）

- 第 29 项：回波功率 5.31e−18 W，噪声 4.53e−14 W ⇒ **−39.3 dB**；
- 第 36 项：`信噪比=8.97…27.12 dB`。

核算：`10·log10(回波×脉压增益/噪声)`，脉压 48.573 dB + MTD ≈1.8 dB ⇒ 口径差 **50.4 dB**，与实测
差值完全一致 ⇒ **数值自洽**。但日志没写"处理后"，外部验证程序按原始功率复算会判成矛盾。
