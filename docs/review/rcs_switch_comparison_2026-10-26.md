# RCS 开关对比方案（2026-10-26）

## 1. 开关位置

`hardware.rcs_physics.enable_physical_rcs`

| 取值 | 检测 RCS 来源 | 验收行口径标注 |
|---|---|---|
| **true** | 球+圆柱物理模型，随视线角变化（`physics_mix_ratio`/`cylinder_weight` 决定混合比）| `视角RCS(物理模型)` |
| **false** | 场景外部输入的标称 RCS（本场景 0.1 m²，恒定）| `外部输入RCS(标称,物理模型关)` |

配置对照文件：

- `remote_identification_radar.lrdr_point.json` —— **物理模型开**（当前部署）
- `remote_identification_radar.lrdr_point_rcs_off.json` —— **物理模型关**（对照组）

切换方法：把对应文件复制到 `FOSimStudio\bin\App\config\remote_identification_radar.json` 后重跑。

## 2. 受影响输出（全部已与开关挂钩）

| 项 | 字段 | 开关=开 | 开关=关 |
|---|---|---|---|
| 第 29 项 | `目标RCS=` | 视角 RCS（随角度变）| 标称 0.1 m² |
| 第 43 项 | `本周期RCS=` | 量测值=单元有效 RCS | 标称 |
| 第 70 项 | `RCS=` | 视角 RCS | 标称 |
| 第 72 项 | `RCS=` | 量测 RCS | 标称 |
| 第 45 项 | `RCS均值/标准差` | 视角表统计（不随开关变化）| 同左 |

## 3. 对比要点（每轮记录）

| 观察量 | 判读 |
|---|---|
| 第 29 项 `回波功率` | 开关打开后应随视角起伏；与标称值比较幅值偏差 |
| 第 36 项 `信噪比` | RCS 变化 → SNR 变化，检查中位数移动方向 |
| 检测拍数 / 首检周期 | 探测距离是否因 RCS 抬高/降低而改变 |
| 47A 类别、73 项型号 | 能量变化是否影响识别（RCS 维均值随之改变）|
| 第 45 项 `RCS均值` | 对照参考：该值始终来自视角表，可用于核对开关是否生效 |

## 4. 预期风险

- 物理模型给出的 RCS 与场景标称值可能相差数量级（`min_rcs_m2=0.01`、`max_rcs_m2=1000` 区间很宽），
  若开启后 RCS 显著抬高，检测距离会明显变远，需重新核对 LRDR 工作点；
- 第 45 项（识别特征）不随开关变化，若两者差异过大，识别与检测的证据会显得不一致。

## 5. 实测三态对照（2026-10-27）

同一想定、同一 LRDR 工作点（3 MW / 2 ms / PRF 200 / 驻留 0.1 s / 脉冲 20 / MTI 开），只改 RCS 开关与混合比。

| 指标 | A：mix = 1.0 | **C：mix = 0.25（定版）** | B：物理模型关 |
|---|---|---|---|
| RCS 标签 | `视角RCS` 964 | `视角RCS` 778 | `外部输入RCS` 74 |
| 第 29 项目标 RCS | 0.356–6.318 m²（中位 3.55，932 种）| **0.493–1.654 m²（中位 1.23，638 种）** | 恒 0.1 m²（1 种）|
| 第 43 项本周期 RCS | 0.36–6.32 m² | **0.49–1.65 m²（511 种）** | 0.1 m² |
| 回波功率中位 | 3.45e-16 W | **6.19e-17 W** | 1.96e-18 W |
| 信噪比中位 | 24.32 dB | **18.19 dB** | 4.68 dB |
| 检测拍数 / 占比 | 961 / 22.5% | **776 / 19.7%** | 74 / 1.7% |
| 47A 判对率 | 94.7%（2796/158）| **99.9%（2389/3）** | 99.5%（557/3）|

结论：`mix = 0.25` 保留视角变化（638 种取值），把 RCS 从“虚高 15.5 dB”收到“+11 dB”，
同时类别判对率最好，定为定版配置。

## 6. 让第 34 项（杂波处理增益）出现的地面/海面目标部署

`RirSurfaceClutterModel::EvaluateClutterNoiseW` 的判据（`RirSurfaceClutterModel.cpp:76-79`）：

```cpp
raw_grazing_deg = el_beamwidth/2 − look_el_deg;      // 本雷达 el_beamwidth = 0.4° → 半波束 0.2°
if (raw_grazing_deg <= 0) return 0;                  // 主瓣完全离地 → 杂波为 0
```

⇒ **只有目标视线仰角 < 0.2° 时才会产生非零杂波**。当前弹道目标在 5,000 km 处仰角约 0.16°（勉强非零）、
更远处升到几度后杂波归零，所以第 34 项基本不出现。

杂波照明距离由波束下沿与地面的交点决定（4/3 等效地球半径，h = 300 m）：

| 目标仰角 | 波束下沿擦地角 | 地面交点距离 |
|---|---|---|
| 0.20° | 0° | ≈ 71 km |
| 0.15° | 0.05° | ≈ 62 km |
| 0.10° | 0.10° | ≈ 58 km |
| 0.05° | 0.15° | ≈ 52 km |

**推荐部署**（Clear 雷达 64.2906N / −149.1903E，扫描中心方位 147.5°、窗口 ±7.5°、仰角 0–55°）：

| 项 | 建议值 |
|---|---|
| 类型 | 海面舰船或地面阵地（静止单元，高度 0）|
| **位置** | 方位 **147.5°**、距离 **60–70 km** → 约 **63.72N / −148.57E** |
| 仰角 | 该距离上视线仰角约 **0.045°**（小于 0.2°，满足杂波条件）|
| RCS | **≥ 1,000 m²**（保证被检测到并形成 detection cell；否则第 34 项无载体）|
| 植被剖面 | 保持 `kOpenGrassland`（σ0 = −28 dB）得弱杂波；改 `kDeciduousForest`（−18 dB）或 `kConiferousForest`（−16 dB）得强杂波 |

按上述部署，预计杂波区约 1.8×10³ m²、杂波 RCS 约 −13 dBsm（草地，10 cm 波长约 0.046 m²），
`clutter_power_w` 将明显大于 0，第 34 项即可输出 `MTI处理后杂波剩余功率` 与 `MTD处理后杂波抑制比`。

**注意**：第 34 项只在“该目标形成了 detection cell”时才会写，因此目标必须真的被检测到；
若想要更强杂波，把植被剖面切到森林档；若想看杂波随距离衰减，可再放一个 90 km 处的同类目标对比。
