# 雷达检测量测与航迹处理接口参数合理性分析

## 检查范围

本报告只统计 `[雷达检测量测与航迹处理交互接口测试]` 记录，共解析 332 条，涉及
目标 208、210、227、231、249。接口数据由检测/量测构造模块交给关联器、航迹生命周期
和 CV/IMM 滤波模块。

合理区间分为两层：

- **硬约束**：类型、单位和数学性质必须始终满足，适用于其他场景。
- **本场景建议区间**：依据本次实测包络、场景配置和少量余量给出，适合回归告警；换场景后应重标定。

## 总体结论

**本次输出参数合理，未发现越界值、非有限值、非法协方差或关联键异常。**

- 332 条记录均完整解析，`Pd` 全部位于 `[0,1]`。
- 332 个协方差矩阵的对角项、二阶主子式和行列式均为正，矩阵正定。
- 协方差最大非对称差为 `0.125 m²`，相对于 `10^5–10^6 m²` 量级属于文本舍入误差。
- 5 个目标各自使用一个稳定关联键；每个目标首次记录为“新建航迹”，其余 327 条为“更新已有航迹”。
- 速度种子全部为零，符合雷达无直接三维速度量测、滤波速度由后验逐步收敛的当前契约。
- 量测位置模长与同周期场景斜距的最大差为 `0.050 m`，差异来自日志小数位舍入。

## 协方差检查

量测协方差的单位为 `m²`，坐标顺序为 ENU `[x,y,z]`。代码由距离/角度随机误差经
球坐标到 ENU 的 Jacobian 投影得到，并给对角线增加 `1e-6 m²` 下限。

| 项目 | 本次实测范围 | 建议判据 | 判定 |
|---|---:|---|---|
| `Rxx` | 172,707.75–568,008.94 m² | 有限且 `>= 1e-6 m²`；本场景回归范围 `1e5–7e5 m²` | 合理 |
| `Ryy` | 1,952,539–4,440,889 m² | 有限且 `>= 1e-6 m²`；本场景回归范围 `1.5e6–5.0e6 m²` | 合理 |
| `Rzz` | 2,084,827.88–4,785,642 m² | 有限且 `>= 1e-6 m²`；本场景回归范围 `1.5e6–5.5e6 m²` | 合理 |
| X 标准差 | 415.58–753.66 m | `sqrt(Rxx)` 有限 | 合理 |
| Y 标准差 | 1,397.33–2,107.34 m | `sqrt(Ryy)` 有限 | 合理 |
| Z 标准差 | 1,443.89–2,187.61 m | `sqrt(Rzz)` 有限 | 合理 |
| `Rxy/Ryx` | 488,615.50–1,435,933.25 m² | `Rij ≈ Rji`，且 `abs(Rij) <= sqrt(Rii*Rjj)` | 合理 |
| `Rxz/Rzx` | 122,983.53–315,161.09 m² | 同上 | 合理 |
| `Ryz/Rzy` | -113,077.98～-35,111.54 m² | 同上；负相关允许存在 | 合理 |
| 最大对称误差 | 0.125 m² | 建议 `<= max(1 m², 1e-5*max(abs(Rij)))` | 合理 |
| 二阶主子式 | 1.6403e10–1.0642e11 m⁴ | 大于 0 | 合理 |
| 行列式 | 4.0980e13–3.6155e14 m⁶ | 大于 0 | 合理 |

协方差在 Y/Z 方向明显大于 X 方向不是异常。目标位于 3616–4151 km 远距离，角度误差经
Jacobian 转换后会形成公里级横向位置标准差，而距离向误差相对较小。当前最大轴向标准差
约占最小目标距离的 `0.061%`，量级与远程探测场景相符。

## 自动验收建议

后续检查程序至少应执行以下规则：

1. 所有浮点字段必须有限，目标 ID、关联键必须非零。
2. `Pd` 必须位于 `[0,1]`，RCS 必须大于 0，位置模长不得超过任务 `max_range_m`。
3. 当前实现的速度种子必须严格为零，防止场景真值速度泄漏进滤波初始化。
4. 协方差必须近似对称、对角项为正，并通过 Cholesky 或特征值非负检查。
5. 同周期一个量测最多对应一个关联键；活动航迹的关联键不得重复。
6. 本场景实测包络只用于回归告警，不应作为其他距离、波束宽度或 SNR 场景的通用物理上限。
