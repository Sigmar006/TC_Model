# Satellite Orbit 模块边界

## 输入边界（冻结）

1. **仅椭球轨道**：偏心率 `e ∈ [0, 1)`；`e ≥ 1`（抛物/双曲）不建模，`Initialize`
   返回 false。
2. **角度单位**：六根数角度一律 deg；`i ∈ [0, 180]`，Ω / ω / M 接受任意有限值，
   M 在初始化时按 2π 归一化。
3. **历元与目标时刻**：UTC 儒略日，须为有限正数；**目标时刻不得早于上次传播时刻**
   ——不执行反向积分，返回 false 并保持当前状态。
4. **失败即不修改**：任何失败路径（非法根数、非有限输入、开普勒迭代半径非正、
   积分溢出、GMST 或坐标转换失败）都不修改已持有的状态，也不写出参。

## 非目标

1. **不做精细摄动**：不建模高阶重力场（J3、J4…）、日月三体引力、太阳光压、
   大气阻力、潮汐与相对论修正。
2. **不做姿态与指向**：只输出位置/速度；姿态、安装角与光轴由探测模块承担。
3. **不做地固系以外的输出约定**：不输出大地坐标（经纬高）、不做地图投影。
4. **不做时间系统转换**：不实现 UT1−UTC、闰秒与 TT/TDB 转换，调用方给定 UTC 儒略日。
5. **不做轨道机动/推力**：不建模 Δv 注入、轨道保持或再入。
6. **不解析场景真值**：不引入目标身份或真值通道。

## 变更规则

1. **物理常数与下限改动需证据**：μ、J2、地球赤道半径、步长下限的变更必须同步
   更新 [algorithms.md](algorithms.md) 的参数表与单元测试。
2. **输出约定不得单方面改变**：ECEF 速度含地球自转输运项补偿，必须与
   `TryEcefVelocityToEci` 保持互逆；改变即破坏与探测链的坐标一致性。
3. **不引入 C++ 异常**：失败一律通过 `bool` 返回，与库内约定一致。
