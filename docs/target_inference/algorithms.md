# Target Inference 算法

## 算法清单

| 算法 | 输入 | 输出 | 证据 |
|---|---|---|---|
| 弹道前向外推（RK4） | ECEF 状态 + 配置 | 航迹点序列 + 落点（地表交点线性插值） | `src/target_inference/TargetInferenceEngine.cpp`；`tests/unit/target_inference/target_inference_engine_test.cpp` |
| 发射点回推 | ECEF 状态 + 配置 | 发射点/时间（大气界面停机门，地表交点/速度停机门为次级） | 同上 |
| 敏度误差预算（J·P·Jᵀ） | 输入协方差 + 扰动重推 | 发射 6×6 协方差 + 发射/落点 1-σ | 同上 |
| 类型融合（先验 + 证据加权） | 速度/高度 + 可选证据向量 | 大类 + 归一化概率 | 同上 |
| 关机点判定（验收通道，助推-滑行状态机） | 逐航迹 ECEF 采样序列 + μ | 四相态 + 关机点/时刻 | `src/target_inference/InferenceAcceptanceRecords.cpp`；同上（Burnout* 测试） |

## 1. 弹道积分与回推

- 动力学：中心引力 `a = −μ·r/|r|³` + 可选指数大气阻力（`drag_ballistic_coefficient_
  m2_per_kg ≤ 0` 关闭；ρ = 1.225·exp(−alt/8500)）。
- 积分器：定步长 RK4，`dt` 可为负（回推即负向积分）；步长 `integration_step_sec`。
- 落点：前向步进中 |r| 跨越地表半径 → 相邻步线性插值交点。
- 发射点：回推步进至地心高降至 `launch_atmosphere_interface_altitude_m`（缺省
  100 km，大气界面停机门）即停，停机点即"助推段上界"估计；界面高度 ≤ 0 关门
  后回落到地表交点（插值），速度 ≤ `launch_speed_threshold_m_per_s` 为次级停机门；
  超过 `launch_max_backtrack_sec` 未触发 → `has_launch=false`。

### 实现边界

- 助推段未建模：回推以大气界面为停机门（2026-08-29 弹道场景审计 A7 处置——旧
  口径回推到地表交点，助推段被弹道外推代替，发射点系统性偏差达数千 km）。界面
  内的助推/静置段不外推；燃烧段模型仍为后续冻结项。
- 守恒律是正确性门：无阻力下单测验证能量 `v²/2 − μ/|r|` 漂移 < 0.1%。

## 2. 敏度误差预算

- 发射协方差：6 个扰动态（固定步长 位置 100 m / 速度 1 m/s）重推回推轨线，得
  6×6 敏度 J；`Σ_launch = J·P·Jᵀ`（完整非对角）。1-σ 取位置对角块最大方差开方。
- 模型误差增长项：助推段未建模的误差随回推时长增长，位置对角叠加
  `(launch_model_error_rate_m_per_s × 回推时长)²`（缺省 50 m/s；审计 A7——
  旧口径 1σ 恒定虚小，与实际发射点偏差量级脱节）。
- 落点 1-σ：同一框架的前向敏度，对角占优近似（Σ_j H_ij²·P_jj）——证据级口径，
  完整 J·P·Jᵀ 为后续冻结项。
- 动力学对扰动步长不敏感（平滑场），固定步长保证确定性。

### 反直觉点

- **σ=0 不是零误差**：输入无协方差时产品 σ 为 0 且 `has_uncertainty=false`——
  这是"无预算"标记，消费方必须区分。
- **误差预算随回推时域增长**：发射点 σ 通常大于当前状态 σ（敏度矩阵范数 > 1），
  这是回推放大的线性化表达；P0 实测表明匹配模型下相关误差部分抵消，放大系数
  ~1（见 target_domain_p0_p1_decision §4.2 结论 3），两口径不矛盾（此处为线性
  上界语义）。

## 3. 类型融合

- 运动学先验（速度/高度门判，8 类得分向量）：
  - 高能量（≥ `high_energy_speed_threshold`）且高空（≥ `high_altitude_threshold`）：
    弹道 0.55 / 导弹 0.30 / 临近空间 0.10；
  - 高能量低空：导弹 0.45 / 战斗机 0.20 / 其它 0.15；
  - 中速（500 ~ 高能量门）：战斗机 0.35 / 轰炸机 0.25 / 其它 0.20；
  - 低速：无人机 0.35 / 其它 0.30 / 战斗机 0.10。
- 融合：`s = w·prior + (1−w)·evidence`（w = `kinematic_type_weight`，默认 0.5）；
  无证据时 s = prior。概率 = s_max/Σs，类别 = argmax。

### 反直觉点

- 先验是**门判启发式不是分类器**：目的是给无识别源的目标一个诚实的运动学倾向；
  有证据时权重可配；阈值门为硬编码业务决策（示例场景验证过），不做配置面
  （YAGNI，同 fusion 适配器先例）。
- **证据通道是多源可组合的预留口**：type_evidence 当前通常由 RIR 识别结论（经
  TARGET-OQ-4 方案 a 键映射）组装；RIR 双产品出口①（特征量测帧，2026-08-18 裁定
  采纳并已于同日 Stage B 落地）上线后，特征级证据可多源组合——组合逻辑归调用方/
  未来识别算法面，本模块只消费得分向量，不感知证据来源。

## 4. 关机点判定（验收通道，助推-滑行状态机）

甲方 2026-08-22 批注「判断其势能+动能最大的地方」；无推力模型（本库设计选择），
判定不建模关机事件，只从逐航迹 ECEF 采样序列推断。状态机为纯函数
（`UpdateBurnoutTracker`），不受验收日志宏门控。

- **助推采样双通道（任一命中）**：
  - 加速度通道：|Δv|/Δt > 2.5·μ/r²（当地重力由 μ/r² 推导，无新物理常数）。推力
    典型几倍重力，滤波速度噪声仅几 m/s——两不相扰。
  - 能量通道：ε = ½|v|² − μ/|r| 逐拍上涨 > 1e-4·μ/r（噪声尺度）且连续 ≥2 拍
    （防单拍噪声；捕捉低于 2.5g 的慢推力）。
  - 物理依据：无阻力滑行 dε/dt = v·a_thrust + v·a_drag = 0——ε 上涨 ⟺ 推力
    做正功；ε 平稳 ⟺ 滑行。
- **关机确认双路径（粘性）**：见过助推后连续 2 拍无助推（关机时刻 = 最后一个助推
  采样，助推段 ε 单调升 ⇒ 峰值即末助推拍）；或 ε 自峰值累计下降 > 1e-3·μ/r（旧
  下降沿口径保留，覆盖单拍增量低于噪声门、无加速度特征的缓升后回落场景——demo
  实测路径）。确认期间峰值锚点冻结（巡航爬升类目标的 ε 缓升不使关机时刻漂移）；
  再次出现助推特征则撤销结论重开（多脉冲/再次加速语义）。
- **相态**：观测中（证据不足暂态）/ 助推中 / 已确认 / 关机点早于跟踪起点（能量自
  首采样即下降）/ 关机点在观测窗口外（从未助推且 ε 距首采样 ≤1e-4·μ/r 连续 5 拍；
  发射预测可用时，以弹道反推至 100 km 大气界面的助推段上界作为关机点回推估计）。
  速度精度门通过但状态仍为观测中时，同样可输出该回推估计；助推中或速度精度门未
  通过时继续输出“正在模拟计算”。日志明确标注回推估计，避免与观测确认混淆。
- **阈值尺度全部由 μ/r 推导**（2.5 倍率与拍数为方法常数，文件内 constexpr）；μ 取
  `TargetInferenceConfig` 单源。平滑带锚定首采样 ε：缓升段累计破带即脱离平稳，
  防把慢推力误判窗口外。

### 实现边界

- 关机时刻分辨率 = 采样周期（末助推拍），不做拍内插值；关机点位置/速度取该拍
  航迹状态。
- 低于噪声尺度的极慢推力（如 2 m/s²、v≈300 m/s 时单拍 Δε≈600 J/kg）在累计破带
  前与滑行不可分——该窗口内相态可能先判窗口外后改判观测中（证据随累积更新）。
- 航迹键跨会话复用会继承状态（静态表会话内累计，与 LastVelocities 先例同语义）。
