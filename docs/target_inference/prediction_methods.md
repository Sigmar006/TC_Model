# 弹道目标四类预测：方法、参数与计算流程

本文按"方法 → 参数 → 流程 → 输出 → 边界"的顺序说明推演模块（target_inference）的四个预测产品。
算法清单与设计取舍见 [algorithms.md](algorithms.md)，模块边界见 [boundaries.md](boundaries.md)。

## 0. 总览

四个产品**共用同一个动力学内核**：中心引力（二体）+ 可选指数大气阻力，定步长 RK4 积分，
`dt` 允许为负（负步长即"往回推"）。差别只在"积到哪儿停"和"谁提供触发条件"。

| 产品 | 方法一句话 | 积分方向 | 终止条件 | 判据项 |
|---|---|---|---|---|
| 弹道轨迹预测 | 从当前状态往前推，按固定间隔输出航迹点 | 前向 | 时域 `prediction_horizon_sec` 用尽 / 撞地 / 状态发散 | 第 20 项 |
| 落点预测 | 前向推到与地球表面相交，交点即落点 | 前向 | `\|r\| ≤ earth_radius_m` | 第 21 项（`SatelliteTarget.log` 段） |
| 发射点预测 | 从当前状态往回推，退到大气界面即停 | **反向** | 大气界面 / 地表 / 低速门 / 回推时限 | 第 22 项 |
| 关机点预测 | 逐拍采样判"助推—滑行"相态，取能量峰值拍；无观测证据时用回推停机点兜底 | 状态机（无需积分）| 关机确认 / 窗口外 | 第 23 项 |

```text
融合航迹（ECEF 位置+速度+6×6 协方差）
        │  InferenceTrackState
        ▼
TargetInferenceEngine::Infer
        ├─① 前向 RK4 ──► 航迹点序列 ────────────────► 第20项 轨迹预报
        │      └─ |r|≤R 线性插值 ──► 落点 ──► 第21项 落点预测
        │                                  └─ 落点 3×3 协方差 ──► 误差椭圆(半长/半短/方位)
        ├─② 反向 RK4 ──► 大气界面停机点 ──────────────► 第22项 发射点预测（含 6×6 协方差）
        ├─③ 助推-滑行状态机（逐拍）──► 关机点 ────────► 第23项 关机点预测
        └─④ 落点 + 报文头 ───────────────────────────► 第25项 落点预报分发
```

## 1. 输入契约

`InferenceTrackState`（`include/1q/target_inference/InferenceTrackState.h`）是唯一入口，
**不含传感器类型、不含坐标系来源**（换系归调用方）：

| 字段 | 单位 | 必填 | 用途 |
|---|---|---|---|
| `key` | — | 是 | 航迹库内键，输出原样带回，关机点状态表按它索引 |
| `sim_time_sec` | s | 是 | 采样时刻，用于关机点状态机的 `Δt`、验收行时间戳 |
| `position`（ECEF） | m | 是 | 积分初值；`\|r\| > earth_radius_m` 才可推演 |
| `velocity_ecef_m_per_s[3]` | m/s | 是 | 积分初值 |
| `has_covariance` / `covariance_ecef[36]` | m²、m²/s² | 否 | 误差预算（无则 `has_uncertainty=false`，σ 输出 0 表示"无预算"） |
| `has_type_evidence` / `type_evidence[8]` | — | 否 | 类型融合（与四个预测无耦合，本文不展开） |

协方差排列为 `[x,vx,y,vy,z,vz]` 行主序（与估计层一致）。可用性判据：
状态有限且 `‖r‖ > earth_radius_m`，否则 `trajectory.valid=false`、四个输出全空。

## 2. 动力学内核

`src/target_inference/TargetInferenceEngine.cpp:37`（加速度）与 `:58`（RK4 单步）。

**引力**（始终启用）：

```text
a_grav = −μ · r / ‖r‖³
```

**阻力**（`drag_ballistic_coefficient_m2_per_kg > 0` 时才启用，缺省 0 = 关闭）：

```text
ρ(h)  = 1.225 · exp(−max(h,0) / 8500)          h = ‖r‖ − earth_radius_m
a_drag = −0.5 · ρ · ‖v‖ · v / β                β = 弹道系数（m²/kg）
```

**积分器**：定步长 RK4，`k1..k4` 四段斜率加权；`dt = max(integration_step_sec, 0.01)`，
前向 `+dt`、回推 `−dt`，同一个函数两用。

**地球模型是球**（`earth_radius_m`），不是椭球。因此地表点的 LLA 反算是球面点，
再按交付口径把高度**强制归零**（椭圆高与球面混用会在中纬度产生约 +5 km 伪高差，
见 `TargetInferenceEngine.cpp:223`）。

## 3. 参数总表

全部来自 `TargetInferenceConfig`（`include/1q/target_inference/TargetInferenceConfig.h`）。

### 3.1 地球与积分

| 参数 | 缺省 | 单位 | 作用 |
|---|---|---|---|
| `earth_mu_m3_per_s2` | 3.986004418e14 | m³/s² | 引力常数，也是关机点阈值的尺度基准（μ/r、μ/r²） |
| `earth_radius_m` | 6378137.0 | m | 球面地表半径；落点/发射点的相交判据 |
| `integration_step_sec` | 1.0 | s | RK4 步长（下限 0.01）；也决定关机点/落点插值的时间分辨率 |
| `drag_ballistic_coefficient_m2_per_kg` | 0.0 | m²/kg | ≤0 关闭阻力；再入段精度开关 |

### 3.2 轨迹预测

| 参数 | 缺省 | 单位 | 作用 |
|---|---|---|---|
| `prediction_horizon_sec` | 300.0 | s | 前向积分时域；**决定"能否算出落点"**（见 §7） |
| `waypoint_interval_sec` | 10.0 | s | 航迹点输出间隔（不足一个步长时按步长） |

> **宿主工作点覆盖**：融合 DP（`sbirsfusiondp_1q.cpp:474`）与精度评估都把它改到
> `prediction_horizon_sec = 1800 s`、`launch_max_backtrack_sec = 1800 s`（库默认 300 / 900）。
> 本文其余缺省值均为库默认，宿主未改。

### 3.3 落点预测

落点没有专属参数，受 `earth_radius_m` / `integration_step_sec` / `prediction_horizon_sec` 三者约束；
误差椭圆由输入协方差与敏度扰动步长决定（见 §5）。

### 3.4 发射点预测（回推）

| 参数 | 缺省 | 单位 | 作用 |
|---|---|---|---|
| `launch_atmosphere_interface_altitude_m` | 100000.0 | m | **主停机门**：回推状态地心高 ≤ 该值即停，停机点 = "助推段上界"估计 |
| `launch_max_backtrack_sec` | 900.0 | s | 回推时长上限；超时未停机 → `has_launch=false`（诚实丢弃） |
| `launch_model_error_rate_m_per_s` | 50.0 | m/s | 模型误差增长率：`σ_model = rate × 回推时长`，叠加到位置对角 |

> 原 `launch_speed_threshold_m_per_s`（30 m/s 次级停机门）已随实现一并删除（2026-11-04）：
> 界面门的判据是速度门判据的超集，速度门永远不可达，`src/` 与配置面都已移除。

### 3.5 关机点预测

方法常数在 `src/target_inference/InferenceAcceptanceRecords.cpp:106-118` 内 `constexpr`，
**尺度全部由 μ/r 推导**，不新增物理常数：

| 常数 | 值 | 含义 |
|---|---|---|
| 加速度通道门 | `2.5 · μ/r²` | `‖Δv‖/Δt` 超过 2.5 倍当地重力即判助推采样 |
| 能量通道门（逐拍） | `1e-4 · μ/r` | `Δε` 上涨超过该值且连续 2 拍 → 助推 |
| 能量下降门 | `1e-3 · μ/r` | `ε` 自峰值累计下降超过该值 → 关机（下降沿路径） |
| 防抖拍数 | 2 | 能量通道连续 2 拍才算（防单拍噪声） |
| 关机确认拍数 | 2 | 见过助推后连续 2 拍无助推 → 确认 |
| 窗口外拍数 | 5 | 从未助推且 ε 平稳 5 拍 → 关机点在观测窗口外 |
| 速度 σ 护栏 | 5.0 m/s | 速度精度未达雷达级时不推进状态机（弱可观测航迹） |

### 3.6 误差预算与分发

| 参数 | 缺省 | 作用 |
|---|---|---|
| 敏度扰动步长 | 位置 100 m / 速度 1 m/s（代码内固定） | 有限差分求 J，见 §5 |
| `impact_distribution_channel` | 空 | 空 = `分发状态=已封装待分发`；非空 = `已发布` |
| `impact_distribution_source_id` / `_target_id` | 0 | 第 25 项 `分发来源ID` / `分发对象ID` |
| `impact_distribution_message_version` | `"1.0"` | 第 25 项 `标准化封装版本` |
| `impact_distribution_message_type` | `"落点预报"` | 第 25 项 `消息类型` |
| `impact_distribution_confidence` | 0.95 | 第 25 项 `置信度`（与 `落点误差范围1σ` 并列，口径不同不互换） |

## 4. 计算流程

### 4.1 弹道轨迹预测（第 20 项）

入口 `TargetInferenceEngine::Infer`（`src/target_inference/TargetInferenceEngine.cpp:180`）。

1. **取初值**：`r0 = position`，`v0 = velocity_ecef_m_per_s`；状态非有限或 `‖r0‖ ≤ R` → `valid=false` 返回。
2. **步进**：`state ← Rk4Step(state, +dt)`，`t += dt`；每步先判状态有限，发散了就停（不抛异常）。
3. **撞地判据**：`‖r_next‖ ≤ R` → 转 4.2 的插值；否则继续。
4. **航迹点**：`t_next ≥ next_waypoint` 时把该步状态转 LLA、压入 `waypoints`，`next_waypoint += max(waypoint_interval_sec, dt)`。
5. **终止**：`t ≥ prediction_horizon_sec` 或撞地或发散。
6. **输出**：`waypoints[]`（相对当前时刻的时间偏移 + LLA）、`has_impact`/落点、后续误差预算。

验收行（`InferenceAcceptanceRecords.cpp:344-424`）只在**当前周期起 10 s 窗口**内统计与展示：
`航路点点数=`（窗口内点数）、`预报时段=[0.0,10.0]s`、`预测点LLA=[+1s:(…);+2s:(…);…]`
（逐秒 10 个点，用静态 `PositionAt` 从当前状态传播、与航迹点同动力学）、
`当前位置经纬高=`；有落点时再加 `落点经纬高=` 与 `落点误差椭圆半长/半短/方位=`。
窗口裁剪是**记录层**行为，不缩短引擎时域——落点解算仍用完整时域。

### 4.2 落点预测（第 21 项，`SatelliteTarget.log` 段）

落点 = 前向弹道与球面地表的交点，**用相邻两步线性插值**（`TargetInferenceEngine.cpp:208-228`）：

```text
r_old = ‖r(t)‖,  r_new = ‖r(t+dt)‖,  r_new ≤ R < r_old
frac  = (r_old − R) / max(r_old − r_new, 1e-9)          ∈ [0,1]
r_imp = r(t) + frac · (r(t+dt) − r(t))
v_imp = v(t) + frac · (v(t+dt) − v(t))
t_imp = t + frac · dt
```

然后 `r_imp → LLA`，并**把高度强制置 0**（球面口径，见 §2）。输出：

| 字段 | 含义 |
|---|---|
| `impact_point` | 落点 LLA（度，高度 0） |
| `impact_time_offset_sec` | 落点时间偏移（相对当前采样，正=未来） |
| `impact_position_sigma_m` | 落点 1-σ（= 位置协方差迹开方，见 §5） |
| `impact_position_covariance_m2[9]` | 落点位置 3×3 协方差（ECEF，行主序） |

**误差椭圆三参数**由该 3×3 协方差投影到水平面后做 2×2 特征分解得到
（`InferenceAcceptanceRecords.cpp:71` 的 `HorizontalEllipseFromCov`，验收行组装在 `:403-422`）：

```text
a = σx²,  b = σxy,  c = σy²
λ1,2 = ½[(a+c) ± √((a−c)² + 4b²)]
半长轴 = √λ1,  半短轴 = √λ2,  方位角 = ½·atan2(2b, a−c)
```

### 4.3 发射点预测（第 22 项）

回推 = 同一 RK4 取 `dt = −dt`（`TargetInferenceEngine.cpp:248-292`），逐拍只有**两个成功出口**，
都不命中就超时丢弃：

```text
① 地表交点：‖r_next‖ ≤ R            → 线性插值（同 4.2 公式），has_surface=true，回推时长记为负
② 大气界面：‖r_next‖ − R ≤ 100 km  → 直接取该步为停机点（主路径；助推段未建模，不允许再往里推）
③ 超时：    |t| ≥ launch_max_backtrack_sec → 返回起点，调用方置 has_launch=false（诚实丢弃）
```

> 原"速度 ≤ 30 m/s 次级停机门"已删除（2026-11-04）：它的判据（低空 ∧ 低速）被 ② 的低空判据
> 完全包含，② 先无条件返回，该分支永远执行不到——留着只会让人误以为可用。

要点：

- **只有高度维的门**：界面门按"地心高 ≤ 100 km"判，不再看速度——早期"任意高度低速即停"的口径
  会让"高空、速度接近零"的保活/合成位置航迹在卫星轨道高度停机，把卫星位置当成发射点。
- 停机后 `→ LLA`；走 ① 的强制高度归零，走 ②③ 的保留真实空中高度（停机点可能在大气层内）。
- 输出：`launch_point`（LLA）、`launch_time_offset_sec`（负值=过去）、`launch_position_sigma_m`、
  `launch_covariance_ecef[36]`。
- 物理含义：**发射点 = "助推段上界"位置，不是发射阵地**。100 km 以上的助推/静置段不外推，
  因此水平偏差量级取决于射程与回推时长（见 §7）。
- **实测对照**（2026-11-04 一轮）：
  `目标键=109 预测发射点地理位置=(37.393,123.756,104878.587) 位置误差1σ=17017.0m`
  —— 高度 104.9 km 与 100 km 的差来自**球面/椭球口径**：停机门按球面地心高判 100 km，
  行内经纬高由 WGS84 椭球反算，中纬度两者相差约 5 km（与 §2 的约 +5 km 伪高差同源）。
  1σ ≈ 17 km ≈ 50 m/s × 340 s（回推时长），与 `launch_model_error_rate_m_per_s` 的设计口径
  严格一致。

### 4.4 关机点预测（第 23 项）

关机点不是积分出来的，是**从逐拍状态序列里判出来的**（无推力模型，`InferenceAcceptanceRecords.cpp:101`
`UpdateBurnoutTracker`，状态随航迹键在会话内累计）。判据来源：甲方批注"判断其势能+动能最大的地方"。

**能量函数**：

```text
ε = ½‖v‖² − μ/‖r‖            （比机械能，J/kg）
```

**第 1 步 · 采样子护栏**（任一命中则该拍不推进状态）：

- `‖r‖ ≤ R`（地表以下，含落地后外推失控的速度）——防止把关机点定到地下；
- 速度 1-σ ≥ 5 m/s（弱可观测航迹，速度欠估计的缓升会被误判成助推）。

**第 2 步 · 助推判别（双通道，任一命中即"助推采样"）**：

```text
加速度通道：‖v(t) − v(t−Δt)‖ / Δt > 2.5 · μ/r²
能量通道：  ε(t) − ε(t−Δt) > 1e-4 · μ/r   （连续 2 拍）
```

物理依据：无阻力滑行 `dε/dt = 0`，ε 上涨 ⟺ 推力做正功；低推力时能量通道生效，
高推力时加速度通道生效。

**第 3 步 · 峰值跟踪**：助推段 ε 单调升 ⇒ **峰值 = 最后一个助推采样 = 关机时刻**。
确认期间峰值锚点冻结（防巡航爬升类目标把关机时刻拖走）；一旦再出现助推特征
（多脉冲/再次点火）就撤销结论、重开跟踪。

**第 4 步 · 关机确认（两条路径）**：

```text
下降沿路径：ε 自峰值累计下降 > 1e-3 · μ/r
滑行路径：  连续 2 拍无助推采样（关机时刻仍取最后一个助推拍）
```

**第 5 步 · 兜底（观测证据不足时）**：相态为"观测中 / 早于跟踪起点 / 窗口外"且推演已算出
发射点回推解时，用**大气界面停机点**作为关机点估计，并在行内标注
`判定依据=大气界面回推估计`——与观测确认的关机点严格区分，不混为一谈。

**第 6 步 · 输出**：`关机时刻=s`、`关机点经纬高=(lat,lon,alt)`、可选 `关机点误差1σ=m`
（用 `PositionSigmaAt` 把当前协方差传播到关机时刻）；未解出时写带原因的
`不适用(尚未解算出关机点)`，不写裸占位。

相态与输出对应：

| 相态 | 含义 | 行内输出 |
|---|---|---|
| 观测中 | 证据不足 | 回推估计（有解时）或"不适用" |
| 助推中 | 正在助推 | "不适用"（推力段不给关机点） |
| 已确认 | 判出峰值拍 | 观测关机点 + 1σ |
| 早于跟踪起点 | 能量自首采样即下降 | 回推估计 |
| 窗口外 | 从未助推且平稳 5 拍 | 回推估计 |

### 4.5 落点预报分发（第 25 项）

在落点行（第 21 项）之上加**报文头**，不做二次计算（`InferenceAcceptanceRecords.cpp:457-486`）：

```text
目标键=…  预测落点=(lat,lon,alt)  落点误差范围1σ=…m
置信度=0.95  标准化封装版本=1.0  消息类型=落点预报
分发状态=已发布 | 已封装待分发  [分发来源ID=…  分发对象ID=…]
```

`落点误差范围1σ` 优先取**落点自身 1-σ**，没有时退回关机点 1-σ（报文是落点预报，
接收方按"误差 ≤ 5% 射程"核对）。

## 5. 误差预算（线性化敏度 J·P·Jᵀ）

只在输入携带协方差时计算（`TargetInferenceEngine.cpp:316-434`）。

**发射点**：对 6 个状态分量各扰动一次（位置 +100 m、速度 +1 m/s），各自重跑回推得
6×6 敏度 `J`，然后：

```text
Σ_launch = J · P · Jᵀ                                  （保留完整非对角）
σ_launch = √(max diag(位置块))                          （1σ 取位置对角最大）
对角线再加模型误差主项：σ_model = launch_model_error_rate_m_per_s × |回推时长|
```

**落点**：同一扰动的**前向**版本，把每个扰动态积分到落点时刻，取位置敏度行 `h_j ∈ R³`，
按对角近似累加：

```text
P_impact = Σ_j h_j · h_jᵀ · P_jj        （j = x,vx,y,vy,z,vz）
```

即 `J·P·Jᵀ` 在 `P` 取对角时的形式；非对角耦合项为二阶小量。落点 1-σ 取迹开方，
3×3 全矩阵同时输出，供椭圆分解使用。

**关机点**：`PositionSigmaAt(track, 关机时刻 − 当前时刻)`，把当前协方差按同一敏度框架
积分到关机时刻（`dt` 可为负，早于当前拍也能算）。

## 7. 边界与反直觉点

1. **时域决定"有没有落点"**：`prediction_horizon_sec` 是"最多往前推多久"，因此只有当
   **剩余飞行时间 ≤ 该时域**时才会算出落点。库默认 300 s、宿主工作点 1800 s；实测宿主一轮
   仿真（飞行约 2,800 s）里，落点行分别在 `t≈1022 s`（目标键 109）与 `t≈1088 s`（目标键 99）
   才首次出现，之后到 `t≈2630/2662 s` 连续输出，跨度约 1,600 s ≈ 1,800 − 200 s 的入窗过程。
   **前期没有落点行是设计行为，不是故障**；要提前预报就调大该参数（代价：每周期积分次数与时延
   按比例上升）。
2. **发射点是"助推段上界"，不是发射阵地**：100 km 以上的助推/静置段不建模，回推停机点
   与真实发射点之间的水平偏差随射程与时域增长；这也是发射点 1σ 里叠加
   `50 m/s × 回推时长` 模型误差项的原因。
3. **关机点靠观测判，不靠动力学算**：无推力模型，判据是能量峰值；速度精度不足时状态机
   不推进，宁可写"不适用"也不给假关机点。
4. **球面地球**：`earth_radius_m` 是赤道半径，地表点高度强制归零；`LLA` 的纬度/经度是
   球面反算结果，与椭球 WGS84 有米级差异，不影响弹道量级判断。
5. **σ=0 不是零误差**：输入无协方差时 `has_uncertainty=false`、σ 输出 0，表示"没有预算"。
6. **阻力缺省关闭**：再入段能量耗散未建模，落点会系统性偏远；需要时把
   `drag_ballistic_coefficient_m2_per_kg` 设为实际弹道系数（典型弹道导弹 1e-3 ~ 1e-2 m²/kg 量级）。
7. **相邻两步线性插值**的时间分辨率是 `integration_step_sec`；把步长从 1 s 调到 0.1 s
   可把落点时间量化误差从秒级降到 0.1 s 级（代价是积分次数 ×10）。
