# log_print —— 仿真日志一键绘图程序

把雷达 / 红外 / 卫星多源仿真日志（约 640 MB）解析后一次性出 **25 张** PNG 图，
用于汇报材料与结果复核。程序自带 Python 运行时，可在**无网络、无 Python、无管理员权限**的内网机器上安装运行。

```bat
offline\install.bat      :: 装一次
offline\run.bat          :: 以后每次出图
```

---

## 1. 目录结构

```text
log_print\
  plot_all.py               一键入口（参数解析、图注册、逐张出图）
  viz\                      绘图实现
    common.py               路径 / 配色 / 字体 / 坐标换算 / 保存
    extract.py              日志解析（6 个扫描器 + 解析缓存）
    figs_antenna.py         图 1–3    天线
    figs_radar.py           图 4–11、16  雷达检测与跟踪
    figs_ir.py              图 12–15  红外与卫星
    figs_signal.py          图 17–25  信号处理与特征
  log\                      放日志（可改路径，见 §4）
  figures\                  出图目录（figNN_*.png）
  offline\                  离线安装包（运行时 + wheel + 脚本）
  .venv\                    开发机虚拟环境（不需要拷到内网）
```

---

## 2. 安装

### 2.1 内网机器 / 没有 Python 的机器（推荐）

1. 把整个 `log_print` 目录拷到内网机器任意**可写**位置
   （不需要拷 `.venv\`、`viz\.cache\`、`log.zip`、`dist\`）。
2. 双击或在 cmd 执行：

   ```bat
   cd /d <拷贝路径>\log_print
   offline\install.bat
   ```

   脚本依次完成：解压自带 Python 3.12.8 → 启用 site-packages → 从 `offline\wheels\` 引导 pip →
   本地安装全部依赖 → 打印各库版本。看到 `Install OK.` 即成功。

3. 验证：

   ```bat
   offline\run.bat --doctor
   ```

安装只写 `log_print\.runtime\`（约 350 MB），不写注册表、不改 PATH、不装服务，不需要管理员。
重复执行是安全的；删掉 `.runtime\` 即可完全卸载。

> 系统要求：Windows 10 1803 及以上（64 位）。安装脚本优先用系统自带 `tar` 解压，
> 不可用时自动回退到 PowerShell `Expand-Archive`。

### 2.2 开发机（已有 Python 3.12）

```bat
cd log_print
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r offline\requirements.txt
.venv\Scripts\python.exe plot_all.py --doctor
.venv\Scripts\python.exe plot_all.py
```

依赖版本固定为：numpy 2.5.4 / pandas 3.1.1 / matplotlib 3.11.2 / scipy 1.18.1
（cp312 win_amd64，与 `offline\wheels\` 内完全一致）。

## 3. 数据准备

把下列文件放进 `log_print\log\`（或用 `--log-dir` 指到别处）：

| 文件 | 内容 | 供图 |
| --- | --- | --- |
| `RadarOutput.log` | 雷达检测/跟踪输出、航迹、干扰与特征 | 3,4,6,7,9,10,16,17,18,20,22,23,24 |
| `RadarExternalInterface.log` | 雷达对外接口（检测、量测、航迹输入） | 4,5,7,8,11 |
| `RadarInternalInterface.log` | 雷达内部接口（检测、特征、功率） | 4,8,11,16,19,21 |
| `IRInternalInterface.log` | 红外内部接口（几何、辐射、跟踪） | 13,14 |
| `IRExternalInterface.log` | 红外对外接口（辐射检测） | 14 |
| `SatelliteTarget.log` | 卫星目标、轨道、落点、事件 | 12,13,15,25 |
| `RadarAntennaGainPatterndata.csv` | 天线增益方向图（127 MB） | 1,2 |
| `Rir_scan_pattern.csv` | 波束扫描驻留表 | 当前 25 张图未使用，仅保留接口 |

要点：

- **文件名必须一致**；可在 `log\` 下按日期/批次分子目录，程序会递归查找同名文件，
  出现多份时取修改时间最新的并打印提示。
- **编码不限**：UTF-8（含 BOM）与 GBK/GB18030 自动识别，`--doctor` 会显示每个文件的判定结果。
- 日志格式需与样例同构：行首 `仿真时间=…s 仿真周期=… [消息类型] 字段=值 …`；
  消息类型与字段名按中文原文匹配，**不要改字段名**。
- 换一批日志后无需清缓存：缓存键包含文件大小与修改时间，自动失效。
- 出图时会一次性读取 6 个日志文件（天线增益 CSV 由图 1–2 按需读取），
  **6 个日志缺任何一个都会报错**（退出码 1），请先跑 `--doctor` 确认。

## 4. 使用方法

```bat
offline\run.bat                          :: 全部 25 张
offline\run.bat --only 1-3               :: 只画 1~3
offline\run.bat --only 1,5,9             :: 只画指定编号
offline\run.bat --refresh                :: 忽略缓存，重新解析日志
offline\run.bat --dpi 300                :: 提高分辨率（默认 200）
offline\run.bat --list                   :: 列出图目录
offline\run.bat --doctor                 :: 环境/数据自检，不画图
offline\run.bat --log-dir D:\data\run1   :: 指定日志目录
offline\run.bat --out-dir D:\out\run1    :: 指定出图目录
offline\run.bat --cache-dir D:\cache     :: 指定缓存目录
```

开发机把 `offline\run.bat` 换成 `.venv\Scripts\python.exe plot_all.py`，参数完全相同。

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--only` | 图编号，支持 `1,3,7` 与 `1-5`，可混用 | 全部 |
| `--refresh` | 删除解析缓存后重解析 | 关 |
| `--dpi` | 出图分辨率 | 200 |
| `--list` | 只列目录，不出图 | — |
| `--doctor` | 自检后退出 | — |
| `--log-dir` | 日志目录 | `log_print\log` |
| `--out-dir` | 出图目录 | `log_print\figures` |
| `--cache-dir` | 解析缓存目录 | `log_print\viz\.cache` |

等价环境变量：`LOG_PRINT_LOG_DIR`、`LOG_PRINT_OUT_DIR`、`LOG_PRINT_CACHE_DIR`
（命令行优先）。程序内不含任何绝对路径，整个目录可以随意搬动、改盘符、放映射盘。

**输出**：`figures\figNN_名称.png`，命名固定，直接覆盖旧图。退出码：`0` 全部成功；`1` 有图失败；
`2` 编号无匹配；`--doctor` 返回 `1` 表示自检发现问题。

## 6. 换一组数据

内网会拿同格式、不同想定的日志来跑，所以图上的文字分两类处理：

**（1）全部现算，自动跟着数据走。** 标题里的记录条数、时间范围、极值/中位/分位，
面板注释里的阈值判定、占比、相关系数，坐标系范围（时间轴、纵横轴上下限）都取自当次数据。
经验结论不是写死的句子，而是按阈值择词，例如：

| 图 | 判据 | 措辞变化 |
| --- | --- | --- |
| 13 | NIS 的 IQR 与 χ²(2) 理论值 2.20 之比 | 偏宽 / 偏窄 / 与理论接近 |
| 14 | SNR 是否全部超过门限 | “全部高于门限” / “高于门限 n/N（x%）” |
| 15 | 落点经度中位 ±60° 主群 | 有离群点才出现“另有 N 个偏离主群…”；否则不提 |
| 17 | 抑制比与干扰功率的 Pearson r | r>0.15 上升 / r<−0.15 下降 / 无显著线性关系 |
| 18 | 两段 log–log 拟合残差平方和最小 | 远近段分界时刻、图例与阴影自动跟随 |
| 19 | 各航迹掩码构成 | 注释按实测占比生成，不再点名“航迹 1/2/4” |
| 20 | `mean.round(3)` 的档位数 | 1 档 / 2 档 / 多档三套措辞与坐标范围 |
| 24 | `span/det` 的实测最小/均值/上十分位 | “实测下界”替代固定常数 |
| 25 | 事件时刻范围与后 25% 时段构成 | 间隔众数、后段主导事件按数据生成 |
| 4、5、8、10、11 | 门限、RCS 是否为常数、主跟踪目标 | 常数才说“恒为”，否则给区间；目标号/航迹号/资源池容量由数据推出 |

**（2）仍与想定绑定，换数据时要人工确认的常量**（都在 `viz\common.py` 或单张图里）：

| 位置 | 常量 | 换数据后怎么办 |
| --- | --- | --- |
| `common.py` `SITE_LAT/SITE_LON/SITE_H` | 雷达站址（ENU 原点） | **必须改**，否则图 8/9 的距离、高度换算整体偏 |
| `common.py` `W_RADAR=(1240, 2870)`、`W_IR=(0, 2950)`、`W_ALL` | 横轴窗口 | 新想定时段不同就改；只影响窗口，不影响数据 |
| 图 13 | χ²(2) 的 1.39 / 2.20 / 5.991 | 检验定义，不随数据变 |
| 图 14 | CFAR/检测门限取自日志 `thr` 字段 | 由日志给出，无需改 |
| 图 15 | 主群半径 ±60° | 落点自身跨 >60° 时需放宽 |
| 图 24 | “实测下界”= `ratio.min()` | 不是理论常数，换数据自动更新 |

换数据后的自查：`--doctor` 确认编码与文件；`--refresh` 重解析；出图后先看各图
副标题里的记录数与时间范围是否与预期一致，再目视 13/15/20/24 这四张判定类图。

## 7. 自检与排错

```bat
offline\run.bat --doctor
```

输出包含：Python 版本与路径、四个库版本、中文字体、7 个数据文件（大小 + 识别出的编码）、目录可写性。
任何一项缺失都会明确列出。

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `runtime not installed` | 未安装 | 先跑 `offline\install.bat` |
| `日志目录里找不到 XXX.log` | 路径/文件名不对 | 放对位置或用 `--log-dir` |
| 图上中文变成方框 | 系统无中文字体 | 安装「微软雅黑」或「黑体」后重跑 |
| 图里数据为空 | 日志编码/格式不符 | `--doctor` 看编码；确认字段名未改 |
| `Permission denied` 写缓存 | 程序目录只读 | 用 `--cache-dir` / `--out-dir` 指到可写目录 |
| 控制台中文乱码 | 代码页不匹配 | 用 `offline\run.bat` 启动（已设 `chcp 65001`） |
| 磁盘占用变大 | 解析缓存 | 删 `viz\.cache\`，下次自动重建 |
| 图想换风格 | 样式集中在 `viz\common.py` | 改配色/字号后直接重跑，无需清缓存 |

## 8. 性能

| 场景 | 耗时 |
| --- | --- |
| 首次解析 640 MB 日志 | 约 10 s（缓存约 170 MB） |
| 有缓存后出 25 张图 | 约 20~30 s |
| 只出 1 张图 | 约 1~2 s |

解析阶段每个日志只顺序读一遍，结果按 `(文件大小, 修改时间, 版本号)` 缓存为 pickle；
日志换了、改了会自动重解析。

## 9. 二次开发

- 改配色/字号/边距：`viz\common.py` 的 `C`、`CYCLE`、`setup_style()`。
- 加一张图：在对应 `figs_*.py` 里写 `def fig26_xxx(data): ...`，并加入该模块的
  `FIGURES = [(26, "fig26_slug", "图 26 标题", fig26_xxx), ...]`，无需改 `plot_all.py`。
- 解析新字段：`viz\extract.py` 里按现有 `f()/v3()/lst()` 构造器拼正则，并 `rows.add(...)`；
  改完把 `CACHE_VERSION` 加 1，避免旧缓存干扰。
- 调试单张图：`plot_all.py --only 26`，出错会打印完整 traceback。
